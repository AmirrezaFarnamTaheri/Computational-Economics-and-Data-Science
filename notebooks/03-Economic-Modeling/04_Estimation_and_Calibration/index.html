    The Lens: From Theory to Reality¶

    What problem are we solving? A model without data is just a parable. To make economic models useful for policy analysis—whether it's predicting the effect of a tax cut or understanding inequality—we must choose their parameters so that they behave like the real world. But many "deep" parameters (like the coefficient of relative risk aversion or the elasticity of substitution) are not directly observable. We cannot simply look them up in a statistical table.

    Why this method? Calibration and Estimation are the bridges between abstract theory and empirical reality. * Calibration: Selecting parameters based on external micro-evidence or long-run averages (e.g., setting the capital share \(\alpha=0.33\) because labor income is consistently ⅔ of GDP). * Estimation (Method of Moments): Systematically choosing parameters to minimize the distance between the model's predicted moments (mean, variance, correlations) and the moments observed in the data.

    This notebook introduces the Method of Simulated Moments (MSM), the standard toolkit for taking structural models to data.

    Learning Objectives¶

    • Distinguish between Calibration (standard) and Estimation (statistical).
    • Implement the Generalized Method of Moments (GMM) logic: matching model moments to data moments.
    • Define the objective function for structural estimation (weighted distance minimization).
    • Apply numerical optimization to find the parameter set that "best fits" the data.
    • Understand identification: which data moments inform which parameters?

    2. The Engine: A High-Performance Aiyagari Solver¶

    To estimate a model, we must solve it hundreds of times. Speed is paramount. We implement the household block of an Aiyagari-style model at a fixed interest rate and exogenous income process. There is no firm-side wage adjustment or market-clearing loop in this estimation exercise. We use numba JIT compilation to accelerate the Value Function Iteration (VFI).

    # --- Helper Functions (JIT Compiled) ---

@njit
def norm_cdf(x):
    """Standard normal CDF implemented for Numba using erf."""
    return 0.5 * (1.0 + math.erf(x / 1.4142135623730951))

@njit
def tauchen(rho, sigma, n=7, m=3):
    """Discretizes AR(1) using Tauchen's method."""
    z_max = m * sigma / np.sqrt(1 - rho**2)
    z_grid = np.linspace(-z_max, z_max, n)
    step = (2 * z_max) / (n - 1)
    P = np.zeros((n, n))
    for i in range(n):
        for j in range(n):
            dist = z_grid[j] - rho*z_grid[i]
            if j == 0:
                P[i, j] = norm_cdf((dist + step/2) / sigma)
            elif j == n - 1:
                P[i, j] = 1 - norm_cdf((dist - step/2) / sigma)
            else:
                P[i, j] = norm_cdf((dist + step/2) / sigma) - norm_cdf((dist - step/2) / sigma)
    return z_grid, P

@njit
def solve_vfi(beta, gamma, r, P, y_grid, a_grid):
    """
    Solves the household problem using Value Function Iteration.
    Returns the policy function (index of optimal savings).
    """
    n_y = len(y_grid)
    n_a = len(a_grid)
    V = np.zeros((n_y, n_a))
    policy = np.zeros((n_y, n_a), dtype=np.int32)

    # Precompute utility for all possible (y, a, a') triples is memory intensive.
    # Instead, we loop. Optimized for Numba.

    tol = 1e-6
    max_iter = 2000

    for it in range(max_iter):
        V_new = np.zeros_like(V)
        max_diff = 0.0

        # Expected Value Function
        EV = P @ V # Matrix multiplication (n_y, n_y) @ (n_y, n_a) -> (n_y, n_a)

        for i in range(n_y):
            y = y_grid[i]
            for j in range(n_a):
                a = a_grid[j]
                cash_on_hand = (1+r)*a + y

                # Find optimal a_prime
                # Exploiting monotonicity of policy would be faster, but brute force is safer here.
                best_val = -1e10
                best_k = 0

                for k in range(n_a):
                    a_prime = a_grid[k]
                    c = cash_on_hand - a_prime
                    if c <= 0:
                        val = -1e10 # Infeasible
                    else:
                        # CRRA Utility
                        util = np.log(c) if gamma == 1 else (c**(1-gamma))/(1-gamma)
                        val = util + beta * EV[i, k]

                    if val > best_val:
                        best_val = val
                        best_k = k

                V_new[i, j] = best_val
                policy[i, j] = best_k
                max_diff = max(max_diff, abs(V_new[i, j] - V[i, j]))

        V = V_new
        if max_diff < tol:
            break

    return policy

@njit
def simulate_moments(policy, P, a_grid, uniforms):
    """
    Simulates agents to calculate stationary moments.

    ``uniforms`` (T, n_sim) are pre-drawn with a seeded Generator outside the
    kernel, so the SMM objective is deterministic and numba-compatible.
    """
    # Initialize agents
    n_y = P.shape[0]
    T, n_sim = uniforms.shape
    y_idx = np.zeros(n_sim, dtype=np.int32) # Start at lowest income
    a_idx = np.zeros(n_sim, dtype=np.int32) # Start with 0 assets

    # Burn-in
    for t in range(T):
        # Update assets
        for i in range(n_sim):
            a_idx[i] = policy[y_idx[i], a_idx[i]]

        # Update income shocks
        # Numba doesn't support np.random.choice with p=vector efficiently in loops
        # Use cumulative sum method
        for i in range(n_sim):
            rand = uniforms[t, i]
            cum_prob = 0.0
            current_y = y_idx[i]
            for next_y in range(n_y):
                cum_prob += P[current_y, next_y]
                if rand <= cum_prob:
                    y_idx[i] = next_y
                    break

    # Calculate Moments from final distribution
    final_assets = np.empty(n_sim)
    for i in range(n_sim):
        final_assets[i] = a_grid[a_idx[i]]

    mean_wealth = np.mean(final_assets)
    std_wealth = np.std(final_assets)

    # Calculate Share of wealth held by top 10%
    final_assets_sorted = np.sort(final_assets)
    top_10_idx = int(n_sim * 0.9)
    top_10_share = np.sum(final_assets_sorted[top_10_idx:]) / np.sum(final_assets)

    return np.array([mean_wealth, std_wealth])

class AiyagariModel:
    """Wrapper class to handle model logic and SMM interface."""
    def __init__(self, r=0.04, rho=0.9, sigma_eps=0.2):
        self.r = r
        self.rho = rho
        self.sigma_eps = sigma_eps

        # Grids
        self.a_grid = np.linspace(0.0, 20.0, 60)
        self.z_grid, self.P = tauchen(rho, sigma_eps, n=5)
        self.y_grid = np.exp(self.z_grid)

    def get_moments(self, beta, gamma):
        # Solve
        policy = solve_vfi(beta, gamma, self.r, self.P, self.y_grid, self.a_grid)
        # Simulate with FIXED draws (drawn once) so the SMM objective is
        # deterministic across evaluations
        rng_sim = np.random.default_rng(42)
        uniforms = rng_sim.random((500, 1000))  # (T, n_sim)
        moments = simulate_moments(policy, self.P, self.a_grid, uniforms)
        return moments

    3. The Estimation Exercise¶

    We will perform a "Monte Carlo" estimation test: 1. Truth: Assume the true world is generated by \(\beta = 0.96\) and \(\gamma = 2.0\). 2. Synthetic Data: Generate "empirical" moments from this truth. 3. Estimation: Pretend we don't know \(\beta\). Start from a guess (e.g., 0.90) and use SMM to recover the true value.

    # 1. Generate Synthetic Truth
true_beta = 0.96
true_gamma = 2.0
model = AiyagariModel(r=0.03)

print("Generating synthetic data from 'True' model...")
true_moments = model.get_moments(true_beta, true_gamma)
print(f"> **Note:** Target Moments -> Mean Wealth: {true_moments[0]:.4f}, Std Dev Wealth: {true_moments[1]:.4f}")

# 2. Define Objective Function
def smm_objective(beta, model, target_moments, gamma_fixed=2.0):
    # Unwrap scalar from array if necessary (scipy minimize passes array)
    if isinstance(beta, np.ndarray):
        beta = float(beta[0])

    if beta <= 0.8 or beta >= 0.99:
        return 1e10 # Constraints

    sim_moments = model.get_moments(beta, gamma_fixed)

    # Weighting matrix (Identity for simplicity)
    # In practice, use inverse variance of moments
    diff = (target_moments - sim_moments)
    loss = np.dot(diff, diff) # Sum of squared errors

    print(f"   Eval: beta={beta:.4f} -> loss={loss:.6f}")
    return loss

# 3. Run Optimization
print("\nStarting SMM Estimation (recovering beta)...")
initial_guess = 0.90

# Using Nelder-Mead as the objective function is effectively step-wise due to discrete grids
res = minimize(smm_objective, x0=[initial_guess], args=(model, true_moments),
               method='Nelder-Mead', options={'xatol': 1e-3, 'disp': True})

estimated_beta = res.x[0]
print(f"\n> **Result:** Estimated Beta: {estimated_beta:.4f} (True: {true_beta})")

    3.1 Visualizing Identification¶

    Inspect the loss profile rather than inferring identification from optimizer success. Discrete asset choices and fixed simulation draws make the sample objective stepwise, so a flat interval can contain several observationally equivalent values of \(\beta\). A coarse plot can reveal a broad minimum, but cannot prove uniqueness or statistical identification.

    betas = np.linspace(0.85, 0.98, 20)
losses = []

print("Mapping objective surface...")
for b in betas:
    l = smm_objective(b, model, true_moments, gamma_fixed=2.0)
    losses.append(l)

plt.figure(figsize=(8, 5))
plt.plot(betas, losses, 'o-', color='darkblue')
plt.axvline(true_beta, color='red', linestyle='--', label='True Beta')
plt.title('SMM Objective Function: Identification of Beta')
plt.xlabel('Discount Factor (Beta)')
plt.ylabel('Loss (Squared Distance)')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

    Summary¶

    In this notebook, we have:

    1. Demonstrated SMM: We estimated a parameter in a non-linear heterogeneous agent model by matching simulated moments to data.
    2. Optimized Performance: We used numba JIT compilation to speed up the VFI solver, making estimation feasible.
    3. Inspected Identification: We profiled the simulated objective to assess sensitivity to \(\beta\), without treating a coarse minimum as proof of unique identification.

    This methodology is standard in modern macroeconomics and structural labor economics. It allows us to fit complex models that do not admit analytical likelihood functions.
