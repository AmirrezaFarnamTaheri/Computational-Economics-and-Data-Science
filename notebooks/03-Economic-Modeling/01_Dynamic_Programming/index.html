    Historical Context — Bellman names dynamic programming (1950s). Working at RAND, Richard Bellman coined the name 'dynamic programming' to hide the mathematics from Defense Secretary Charles Wilson ('the word research bothered him'), as he later recounted in his autobiography. His 1957 book stated the principle of optimality used in every value function iteration below.

    The Lens: The Recursive Structure of Choice¶

    What problem are we solving? Most economic decisions are not one-off events; they are sequences of choices made over time. A firm decides investment today, tomorrow, and next year. A worker decides whether to accept a job offer or keep searching. A central bank sets interest rates month after month. To optimize a sequence of decisions, we must account for how today's choice affects tomorrow's possibilities. This is the realm of Dynamic Programming.

    Why this method? Directly optimizing an infinite sequence is often computationally impractical. Dynamic programming exploits recursive structure to separate two parts: 1. Current Reward: What do I get today? 2. Continuation Value: What is the value of the state I leave for tomorrow? The Bellman Equation formalizes this recursive logic: $$ V(x) = \max_{a} { u(x, a) + \beta V(x') } $$ By finding the fixed point of this equation, we solve the entire infinite-horizon problem at once.

    This notebook introduces the machinery of DP: the Bellman Operator, Value Function Iteration, and the Contraction Mapping Theorem.

    1. The Principle of Optimality: A Cake Eating Problem¶

    To build intuition, we start with one of the simplest DP problems: the "cake eating" problem. An agent has a cake of size \(x_t\) at time \(t\). They must decide how much to eat, \(c_t\), and how much to leave, \(x_{t+1}\). The problem is finite, lasting for \(T\) periods. The agent's problem is to maximize lifetime utility: $ \max_{c_0, ..., c_T} \sum_{t=0}^{T} \beta^t u(c_t) $, subject to the resource constraint \(x_{t+1} = x_t - c_t\). We solve this using backward induction.

    • Period T: The agent eats whatever is left. The value function is \(V_T(x_T) = u(x_T)\).
    • Period T-1: The agent chooses \(c_{T-1}\) to maximize current plus discounted future utility. This gives the Bellman equation: $$ V_{T-1}(x_{T-1}) = \max_{0 \le c_{T-1} \le x_{T-1}} { u(c_{T-1}) + \beta V_T(x_{T-1} - c_{T-1}) } $$

    Solving the Finite Horizon Cake Eating Problem¶

    T = 10; BETA_CE = 0.95; X_GRID = np.linspace(0.01, 10, 100)
# We use the log utility function for its convenient analytical properties.
@njit
def u_log(c): return np.log(c)

# We use NumPy arrays to store the value and policy functions for each period.
V_storage = np.zeros((T + 1, len(X_GRID)))
C_storage = np.zeros((T + 1, len(X_GRID)))

# In the last period, the agent consumes all remaining cake.
V_storage[T, :] = u_log(X_GRID)
C_storage[T, :] = X_GRID

# We iterate backwards from the second-to-last period.
for t in range(T - 1, -1, -1):
    V_next = V_storage[t + 1, :]
    for i, x in enumerate(X_GRID):
        # The objective function is the negative of the Bellman equation, since we are minimizing.
        def objective(c): # Minimize negative utility
            x_next = x - c
            # We use linear interpolation to find the value of the next state, which may not be on the grid.
            if x_next <= 0:
                return np.inf
            # Log utility implies V_t(x)=A_t+B_t log(x). Extend this
            # analytical boundary form instead of inventing cake below X_GRID[0].
            log_x = np.log(X_GRID)
            slope = (V_next[1] - V_next[0]) / (log_x[1] - log_x[0])
            v_next_interp = V_next[0] + slope * (np.log(x_next) - log_x[0])
            return -(u_log(c) + BETA_CE * v_next_interp)
        # We use a bounded scalar minimizer to find the optimal consumption.
        res = minimize_scalar(objective, bounds=(1e-12, x), method='bounded', options={'xatol': 1e-12})
        V_storage[t, i] = -res.fun
        C_storage[t, i] = res.x

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 6))
ax1.plot(X_GRID, V_storage[0, :], label='V_0(x)'); ax1.plot(X_GRID, V_storage[T-1, :], label=f'V_{T-1}(x)'); ax1.plot(X_GRID, V_storage[T, :], label='V_T(x)')
ax1.set_title('Value Functions'); ax1.set(xlabel='Cake Size (x)', ylabel='Value'); ax1.legend()

    2. The Bellman Equation for Infinite Horizon Problems¶

    For an infinite horizon stochastic problem, the Bellman equation takes a more general, recursive form: $$ V(s) = \max_{a \in \Gamma(s)} { u(s, a) + \beta E[V(s')] } $$ where \(s\) is the state, \(a\) is the action, \(u(s,a)\) is the reward, and \(s'\) is the next period's state. The solution is a value function \(V(s)\) and a policy function \(\sigma(s) = \arg\max \{...\}\).

    The Principle of Optimality: Statement and Proof¶

    So far we have asserted that the value of the infinite-horizon problem satisfies the Bellman equation. That assertion is the Principle of Optimality, and it deserves a proof: everything else in this notebook — VFI, PFI, the policy functions we simulate — rests on it. We prove it in the deterministic case, where the notation is cleanest, and then note the one-line extension to stochastic problems.

    Setup (the sequence problem). The state evolves as \(s_{t+1} = m(s_t, a_t)\), with actions constrained by \(a_t \in \Gamma(s_t)\). A feasible plan from \(s\) is a sequence \(\pi = (a_0, a_1, a_2, \ldots)\) such that each action is feasible at the state it induces. Its lifetime payoff is

    \[ W(s, \pi) \;=\; \sum_{t=0}^{\infty} \beta^t\, u(s_t, a_t), \qquad s_0 = s, \]

    and the value function of the sequence problem is the best achievable payoff:

    \[ V^*(s) \;=\; \sup_{\pi \text{ feasible from } s} W(s, \pi). \]

    We assume \(\beta \in (0,1)\) and \(|u(s,a)| \le B\) for all feasible pairs. Boundedness guarantees the infinite sum converges absolutely and \(|V^*(s)| \le B/(1-\beta)\), so every expression below is finite.

    Theorem (Principle of Optimality). Under the assumptions above, the sequence-problem value function satisfies the Bellman equation: $$ V^(s) \;=\; \sup_{a \in \Gamma(s)} \left{\, u(s, a) + \beta\, V^\big(m(s, a)\big) \,\right} \quad \text{for every } s. $$

    Proof. The engine of the whole argument is one decomposition. Any feasible plan \(\pi = (a_0, a_1, a_2, \ldots)\) from \(s\) splits into its first action and its continuation plan \(\pi_1 = (a_1, a_2, \ldots)\), which is itself a feasible plan from \(s_1 = m(s, a_0)\). Pulling the \(t=0\) term out of the sum and re-indexing:

    \[ W(s, \pi) \;=\; u(s, a_0) + \beta \sum_{t=0}^{\infty} \beta^{t}\, u(s_{t+1}, a_{t+1}) \;=\; u(s, a_0) + \beta\, W(s_1, \pi_1). \]

    This step is where the two structural assumptions of dynamic programming do their work: additive separability of payoffs lets the sum split, and geometric discounting makes the continuation payoff look exactly like a fresh copy of the original problem, scaled by \(\beta\). We now squeeze \(V^*\) between two inequalities.

    Step 1 (\(\le\)). Take any feasible plan \(\pi\) from \(s\). Its continuation payoff cannot beat the best available from \(s_1\), so \(W(s_1, \pi_1) \le V^*(s_1)\), and therefore

    \[ W(s, \pi) \;\le\; u(s, a_0) + \beta\, V^*\big(m(s, a_0)\big) \;\le\; \sup_{a \in \Gamma(s)} \left\{ u(s, a) + \beta\, V^*\big(m(s, a)\big) \right\}. \]

    The right-hand side no longer depends on \(\pi\), so taking the supremum over all feasible plans on the left gives \(V^*(s) \le \sup_{a} \{ u(s,a) + \beta V^*(m(s,a)) \}\).

    Step 2 (\(\ge\)). Fix any action \(a \in \Gamma(s)\) and any \(\varepsilon > 0\). By the definition of a supremum, there exists a feasible plan \(\pi'\) from \(s' = m(s, a)\) that is \(\varepsilon\)-optimal: \(W(s', \pi') \ge V^*(s') - \varepsilon\). Concatenating \(a\) with \(\pi'\) produces a feasible plan from \(s\) whose payoff, by the decomposition, is

    \[ u(s, a) + \beta\, W(s', \pi') \;\ge\; u(s, a) + \beta\, V^*(s') - \beta\varepsilon. \]

    Since \(V^*(s)\) dominates the payoff of every feasible plan, \(V^*(s) \ge u(s,a) + \beta V^*(m(s,a)) - \beta\varepsilon\). Letting \(\varepsilon \to 0\) and then taking the supremum over \(a \in \Gamma(s)\) gives \(V^*(s) \ge \sup_a \{ u(s,a) + \beta V^*(m(s,a)) \}\).

    Steps 1 and 2 together give equality. \(\blacksquare\)

    The converse (verification theorem). The Principle of Optimality says \(V^*\) solves the Bellman equation — but could the equation have other solutions that VFI might converge to instead? Not among bounded functions:

    Theorem (Verification). If a bounded function \(W\) satisfies the Bellman equation, then \(W = V^*\); and any stationary policy \(\sigma\) with \(\sigma(s) \in \arg\max_a \{u(s,a) + \beta W(m(s,a))\}\) is optimal.

    Proof sketch. Iterate the Bellman equation forward \(n\) times along any feasible plan: because the sup dominates each particular action, \(W(s) \ge \sum_{t=0}^{n-1} \beta^t u(s_t, a_t) + \beta^n W(s_n)\), and following \(\sigma\) (or \(\varepsilon\)-optimal actions) achieves this within \(\varepsilon \sum_t \beta^t\). Boundedness of \(W\) forces the tail \(\beta^n W(s_n) \to 0\) as \(n \to \infty\) — this is exactly the role of discounting — leaving \(W(s) \ge W(s, \pi)\) for every plan and \(W(s) \le V^*(s) + \varepsilon/(1-\beta)\) along the \(\varepsilon\)-optimal one. Hence \(W = V^*\). The same tail argument shows the plan generated by \(\sigma\) attains the supremum. \(\blacksquare\)

    Uniqueness also follows from a different, purely topological route: §2.1 below shows the Bellman operator is a contraction mapping, and the Banach fixed-point theorem (proved in Appendix/A1-Real-Analysis.ipynb) delivers a unique bounded fixed point — necessarily \(V^*\), by the two theorems above. The two arguments are complementary: the proofs here explain why the fixed point is the economically right object, while the contraction property explains why iteration finds it, at geometric rate \(\beta\).

    Stochastic extension. With a stochastic transition \(s' \sim Q(\cdot \mid s, a)\), replace \(V^*(m(s,a))\) by \(\mathbb{E}[V^*(s') \mid s, a]\) and payoffs by their expectations. The decomposition step goes through verbatim by the law of iterated expectations — the expected payoff of a plan splits into today's reward plus \(\beta\) times the conditional expectation of the continuation value — and both inequalities are preserved under expectations. (Formally one also needs the plan's actions to be measurable functions of observed histories; for the finite-state chains we compute with in this notebook, this is automatic.)

    2.1 The Bellman Operator and Contraction Mappings¶

    The Bellman operator maps a candidate value function \(v\) to $\((Tv)(s)=\sup_{a\in\Gamma(s)}\{u(s,a)+\beta\mathbb E[v(s')\mid s,a]\}.\)$ Assume nonempty feasible sets, bounded rewards, a probability transition kernel, and \(0<\beta<1\). On bounded functions, the sup norm gives a complete space and \(T\) is a contraction. Preserving continuity requires additional continuity and compactness assumptions; bounded rewards alone do not establish that property.

    For any fixed state-action pair, $\(\left|\beta\mathbb E[v_1(s')-v_2(s')\mid s,a]\right|\le\beta\|v_1-v_2\|_\infty.\)$ Use \(|\sup_a f(a)-\sup_a g(a)|\le\sup_a|f(a)-g(a)|\), then take the supremum over states: $\(\|Tv_1-Tv_2\|_\infty\le\beta\|v_1-v_2\|_\infty.\)$ The action in the conditional expectation must remain fixed while applying this bound. Expectations under two different maximizing actions cannot be treated as the same expectation.

    The contraction theorem gives a unique bounded fixed point \(V^*\) and convergence of VFI from any bounded initial guess. A computable error certificate is $\(\|v-V^*\|_\infty\le\frac{\|Tv-v\|_\infty}{1-\beta}.\)$ The finite-grid model below has bounded feasible rewards. Log/CRRA utility on an unrestricted continuous consumption domain needs separate boundary and existence arguments.

    2.2 The State-Action Value Function (Q-Function)¶

    An alternative representation, central to reinforcement learning, is the state-action value function, or Q-function. It represents the value of being in state \(s\) and taking action \(a\): $$ Q(s, a) = u(s, a) + \beta E[V(s')] $$ The value function is then simply the maximum over all possible actions: \(V(s) = \max_a Q(s, a)\). Substituting this into the first equation gives a Bellman equation for Q: $$ Q(s, a) = u(s, a) + \beta E[\max_{a'} Q(s', a')] $$

    3. A Canonical Model: The Stochastic Growth Model¶

    We solve a version of the Bewley-Huggett-Aiyagari model of household savings with uninsurable income risk. The Bellman equation is: $$ V(a, y) = \max_{0 < a' \le (1+r)a+y} \left{ u((1+r)a+y-a') + \beta \sum_{y'} P(y'|y) V(a', y') \right} $$

    3.1 Discretizing the Income Process¶

    We assume log-income, \(z_t = \log(y_t)\), follows an AR(1) process: \(z_{t+1} = \rho z_t + \sigma \epsilon_{t+1}\). We use Tauchen's method to approximate this with a finite-state Markov chain.

    Discretizing the Income Process¶

    # Numba doesn't support scipy.stats.norm, so we create a JIT-compatible version
@njit
def norm_cdf_numba(x):
    'Cumulative distribution function for the standard normal distribution'
    return (1.0 + math.erf(x / np.sqrt(2.0))) / 2.0

@njit
def tauchen(rho, sigma_u, m=3, n=7):
    z_max = m * sigma_u / np.sqrt(1 - rho**2)
    z_grid = np.linspace(-z_max, z_max, n)
    step = (z_grid[-1] - z_grid[0]) / (n - 1)
    P = np.empty((n, n))
    for i in range(n):
        for j in range(n):
            z_j_low = z_grid[j] - step/2
            z_j_high = z_grid[j] + step/2
            if j == 0:
                # First interval extends to -infinity so rows sum to exactly 1.
                P[i, j] = norm_cdf_numba((z_j_high - rho * z_grid[i]) / sigma_u)
            elif j == n - 1:
                # Last interval extends to +infinity.
                P[i, j] = 1.0 - norm_cdf_numba((z_j_low - rho * z_grid[i]) / sigma_u)
            else:
                P[i, j] = norm_cdf_numba((z_j_high - rho * z_grid[i]) / sigma_u) - \
                          norm_cdf_numba((z_j_low - rho * z_grid[i]) / sigma_u)
    return z_grid, P

rho_y, sigma_y = 0.95, 0.1
z_grid, P_TRANS = tauchen(rho_y, sigma_y)
Y_STATES = np.exp(z_grid)

    3.2 Building the Model Primitives¶

    To solve the model, we need to create the reward matrix R and the transition probability matrix Q. The state is the tuple (assets, income), and the action is the choice of next period's assets a'. R[s, a] is the utility from being in state s and choosing action a. Q[s, a, s'] is the probability of transitioning to state s' given state s and action a.

    Building the Model Primitives¶

    # --- 1. Define Model Parameters ---
sgm_params = {
    'beta': 0.96,       # Discount factor
    'gamma': 2.0,       # CRRA coefficient
    'r': 0.03,          # Risk-free interest rate
    'a_grid': np.linspace(0.01, 50, 150), # Asset grid
    'y_states': Y_STATES, # Income states from Tauchen
    'P_trans': P_TRANS  # Transition matrix from Tauchen
}

n_a = len(sgm_params['a_grid'])
n_y = len(sgm_params['y_states'])

# --- 2. Create Reward and Transition Matrices ---
@njit
def u_crra(c, gamma):
    return np.log(c) if gamma == 1 else (c**(1 - gamma)) / (1 - gamma)

R = np.full((n_a, n_y, n_a), -1e10)
for i in range(n_a):
    for j in range(n_y):
        for k in range(n_a):
            a = sgm_params['a_grid'][i]
            y = sgm_params['y_states'][j]
            a_prime = sgm_params['a_grid'][k]
            c = (1 + sgm_params['r']) * a + y - a_prime
            if c > 0: R[i, j, k] = u_crra(c, sgm_params['gamma'])

Q = np.zeros((n_a, n_y, n_a, n_y))
for j in range(n_y):
    Q[:, j, :, :] = sgm_params['P_trans'][j, :]

print("Built R and Q matrices for the stochastic growth model.")

    4. Numerical Solution Algorithms¶

    Figure: Value function iteration converging on the cake-eating problem.. For pedagogical clarity, we now implement the core solution algorithms directly in the notebook, using Numba's @njit decorator to ensure high performance.

    4.1 Value Function Iteration (VFI)¶

    VFI directly implements the Bellman operator as an update rule.

    @njit
def value_function_iteration(R, Q, beta, tol=1e-6, max_iter=1000):
    """Solves a discrete DP model using value function iteration.

    Parameters
    ----------
    R : np.ndarray, shape (n_s1, n_s2, n_a)
        Reward matrix.
    Q : np.ndarray, shape (n_s1, n_s2, n_a, n_s2)
        State transition probability matrix.
    beta : float
        Discount factor.
    tol : float, optional
        Tolerance for convergence.
    max_iter : int, optional
        Maximum number of iterations.

    Returns
    -------
    V : np.ndarray, shape (n_s1, n_s2)
        Converged value function.
    history : list
        List of value functions at each iteration.
    """
    n_a, n_y, _, _ = Q.shape
    V = np.zeros((n_a, n_y))
    P_trans = Q[0, :, 0, :]  # Extract P_trans from Q
    history = []
    for i in range(max_iter):
        E_V = V @ P_trans.T
        V_new = np.empty_like(V)
        for s_i in range(n_a):
            for s_j in range(n_y):
                q_s = R[s_i, s_j, :] + beta * E_V[:, s_j]
                V_new[s_i, s_j] = np.max(q_s)

        diff = np.max(np.abs(V - V_new))
        V = V_new
        if diff < tol:
            # Update V BEFORE returning, so the result is the converged
            # function rather than the second-to-last iterate.
            break
        history.append(V.flatten())
    return V, history

print("VFI algorithm compiled.")

    4.2 Policy Function Iteration (PFI)¶

    PFI alternates between evaluating a policy and improving upon it.

    @njit
def policy_function_iteration(R, Q, beta, tol=1e-8, max_iter=100):
    """Solve the discrete DP by exact policy evaluation and improvement.

    The state is ``(asset_index, exogenous_state)`` and an action selects the
    next asset index. ``Q[0, :, 0, :]`` contains the exogenous transition
    matrix used throughout this notebook. Policy evaluation solves
    ``(I - beta P_pi) V_pi = r_pi`` exactly, then the greedy step improves the
    policy.
    """
    n_a, n_y, _, _ = Q.shape
    n_states = n_a * n_y
    P_trans = Q[0, :, 0, :]
    policy = np.zeros((n_a, n_y), dtype=np.int32)
    V = np.zeros((n_a, n_y))

    for _ in range(max_iter):
        # Exact policy evaluation.
        transition = np.zeros((n_states, n_states))
        rewards = np.empty(n_states)
        for a_now in range(n_a):
            for y_now in range(n_y):
                row = a_now * n_y + y_now
                a_next = policy[a_now, y_now]
                rewards[row] = R[a_now, y_now, a_next]
                for y_next in range(n_y):
                    col = a_next * n_y + y_next
                    transition[row, col] = P_trans[y_now, y_next]

        lhs = np.eye(n_states) - beta * transition
        V_new = np.linalg.solve(lhs, rewards).reshape((n_a, n_y))

        # Greedy policy improvement.
        expected_value = V_new @ P_trans.T
        policy_new = np.empty_like(policy)
        for a_now in range(n_a):
            for y_now in range(n_y):
                q_values = R[a_now, y_now, :] + beta * expected_value[:, y_now]
                policy_new[a_now, y_now] = np.argmax(q_values)

        value_change = np.max(np.abs(V_new - V))
        stable = np.array_equal(policy_new, policy)
        V = V_new
        policy = policy_new
        if stable and value_change < tol:
            break

    return V, policy

print("Exact policy-function iteration algorithm compiled.")

    4.3 Howard's Policy Improvement Algorithm¶

    Howard's PFI is a more practical variant that avoids the costly matrix inversion of the policy evaluation step. Instead, it approximates the value of the current policy by running a fixed, small number of VFI steps.

    @njit
def howard_policy_iteration(R, Q, beta, m=20, max_iter=200, tol=1e-6):
    """Solves a discrete DP model using Howard's Policy Iteration.

    This is a faster variant of PFI that approximates the policy evaluation
    step with a fixed number of VFI steps.

    Parameters
    ----------
    m : int, optional
        Number of VFI steps to run in the evaluation phase.
    max_iter : int, optional
        Maximum number of policy improvement iterations.

    Returns
    -------
    V : np.ndarray
        Converged value function.
    policy : np.ndarray
        Optimal policy array.
    """
    n_a, n_y, _, _ = Q.shape
    V = np.zeros((n_a, n_y))
    policy = np.zeros((n_a, n_y), dtype=np.int32)
    P_trans = Q[0, :, 0, :]  # Extract P_trans from Q
    for i in range(max_iter):
        # Policy Evaluation (m VFI steps)
        for _ in range(m):
            E_V = V @ P_trans.T
            V_policy = np.empty_like(V)
            for s_i in range(n_a):
                for s_j in range(n_y):
                    a = policy[s_i, s_j]
                    V_policy[s_i, s_j] = R[s_i, s_j, a] + beta * E_V[a, s_j]
            V = V_policy

        # Policy Improvement
        E_V = V @ P_trans.T
        policy_new = np.empty_like(policy)
        residual = 0.0
        for s_i in range(n_a):
            for s_j in range(n_y):
                q_s = R[s_i, s_j, :] + beta * E_V[:, s_j]
                policy_new[s_i, s_j] = np.argmax(q_s)
                residual = max(residual, abs(np.max(q_s) - V[s_i, s_j]))

        if np.array_equal(policy, policy_new) and residual < tol:
            break
        policy = policy_new
    return V, policy

print("Howard's PFI algorithm compiled.")

    5.1 The Value and Policy Functions¶

    The value function increases with assets. The saving policy \(a'(a,y)\) reflects available resources, patience, and income risk. At fixed assets, a lower income realization need not raise saving: households often draw down their buffer to smooth consumption.

    Precautionary saving is a comparison across risk environments, holding resources and expected income comparable, not the difference between the low- and high-income policy curves. For CRRA preferences, positive prudence (\(u'''(c)>0\)) supports the precautionary motive. Borrowing limits and income persistence also shape the quantitative response.

    6. Simulating the Stationary Distribution¶

    After solving for the optimal policy, a key economic question is what the long-run distribution of assets looks like. We can find this by simulating a large panel of households over a long time horizon, where each household follows the optimal policy rule.

    Simulating the Stationary Asset Distribution¶

# OUTSIDE the jitted kernel with a Generator and passed in (numba nopython
# mode cannot capture Generator objects from the enclosing scope).
rng_sim = np.random.default_rng(42)
SIM_UNIFORMS = rng_sim.random((500, 5000))  # (t_steps, n_agents)


@njit
def simulate_asset_distribution(policy_indices, P_trans, a_grid, uniforms):
    t_steps, n_agents = uniforms.shape
    a_indices = np.zeros(n_agents, dtype=np.int32)
    y_indices = np.zeros(n_agents, dtype=np.int32)

    for t in range(t_steps):
        # Update assets based on policy
        new_a_indices = np.empty_like(a_indices)
        for i in range(n_agents):
            new_a_indices[i] = policy_indices[a_indices[i], y_indices[i]]
        a_indices = new_a_indices

        # Update income based on Markov chain
        new_y_indices = np.empty_like(y_indices)
        for i in range(n_agents):
            new_y_indices[i] = np.searchsorted(
                np.cumsum(P_trans[y_indices[i], :]), uniforms[t, i]
            )
        y_indices = new_y_indices

    return a_grid[a_indices]

    2. Core relation

    \[V_{T-1}(x_{T-1}) = \max_{0 \le c_{T-1} \le x_{T-1}} \{ u(c_{T-1}) + \beta V_T(x_{T-1} - c_{T-1}) \}\]

    3. Core relation

    \[V(s) = \max_{a \in \Gamma(s)} \{ u(s, a) + \beta E[V(s')] \}\]

    4. Core relation

    \[W(s, \pi) \;=\; \sum_{t=0}^{\infty} \beta^t\, u(s_t, a_t), \qquad s_0 = s,\]

    Common Pitfalls in This Lecture

    • Premature VFI stopping. A value update is not a value-error bound without the factor \(1/(1-\beta)\). Near-tied actions can switch while values barely move. Report the Bellman residual and policy sensitivity; an unchanged policy alone does not certify convergence of approximate policy evaluation.
    • Extrapolating off-grid. Interpolated policy rules are valid only inside the grid. Evaluating \(k'\) slightly outside the capital grid can imply negative consumption and crash the Bellman step; clamp states to the grid or extend it.

    7. Summary¶

    Dynamic programming provides a unified language for sequential decision-making. By defining a state space and a recursive Bellman equation, we can solve complex infinite-horizon problems that would otherwise be intractable.

    Key Takeaways: - Bellman Equation: Breaks infinite problems into a two-period choice (today vs. expected discounted future). - Contraction Mapping: The theoretical guarantee that allows us to find a unique solution by simply iterating the Bellman operator (VFI). - Algorithms: VFI is robust but slow. Howard's Policy Iteration is much faster by avoiding costly max operations at every step. - Precautionary Savings: In the presence of uninsurable risk (incomplete markets), agents save more than they would in a deterministic world to buffer against shocks. This is a fundamental result in modern macroeconomics.

    Mastery of these tools—discretization, VFI/PFI, and simulation—is the gateway to solving the advanced heterogeneous agent models (like HANK) that dominate frontier research.

    Summary¶

    Dynamic Programming is the grammar of modern macroeconomics.

    Key Takeaways: * Recursive Thinking: Don't solve for a sequence; solve for a rule (policy function). * The Bellman Operator: It maps a guess of the value function to a better guess. Iterating it leads to the truth. * The Curse of Dimensionality: As the number of state variables increases, the computational burden grows exponentially. This is the main limit of standard DP methods.
