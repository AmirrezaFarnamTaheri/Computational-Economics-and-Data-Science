    07 Numerical Integration¶

    The Lens: Expectations as Integrals¶

    What problem are we solving?
    Economics is full of uncertainty. Agents make decisions based on expectations of the future. * Expected Utility: \(E[u(c')] = \int u(c') f(c') dc'\) * Asset Pricing: \(P_t = E_t[M_{t+1} X_{t+1}]\)

    Mathematically, an expectation is a definite integral. To solve dynamic models with risk, we must compute these integrals numerically.

    Why this method?
    We cannot sum over a continuum. We must approximate the integral as a weighted sum: \(\int f(x) dx \approx \sum w_i f(x_i)\). * Newton-Cotes (Trapezoid): Robust, good for general functions. * Gaussian Quadrature: Extremely accurate for smooth functions (e.g., Normal shocks). * Monte Carlo: A robust way to survive the Curse of Dimensionality (beyond a few dimensions, deterministic grids become impractical). * Quasi-Monte Carlo (QMC): Uses low-discrepancy sequences to beat random sampling (\(O(N^{-1})\) convergence). * MCMC (Metropolis-Hastings): Essential for Bayesian inference when we can't sample directly from the posterior.

    Economic question. In 07 Numerical Integration, what must remain economically invariant when the computational representation changes? In economic computation, an algorithm is part of the model: convergence tolerances, conditioning, discretization, and stopping rules can alter the apparent equilibrium. The central question is therefore not merely whether a routine returns a number, but whether that number is stable under tighter tolerances, alternative initial conditions, and an independent method. Treat every numerical result as an approximation with a measurable error budget.

    Learning Objectives¶

    By the end of this notebook, you will be able to: 1. Implement Trapezoidal and Simpson's rules. 2. Apply Gaussian Quadrature (Gauss-Hermite) for Normally distributed risks. 3. Utilize Monte Carlo integration for high-dimensional problems. 4. Price a financial option using simulation.

    1. Deterministic Quadrature¶

    We approximate \(I = \int_a^b f(x) dx \approx \sum_{i=1}^n w_i f(x_i)\).

    1.1 Newton-Cotes (Trapezoidal Rule)¶

    Approximates the function as piecewise linear segments. Robust but slow (\(O(N^{-2})\)).

    1.2 Gaussian Quadrature¶

    Optimally chooses nodes and weights. An \(N\)-point rule integrates a polynomial of degree \(2N-1\) exactly. * Gauss-Legendre: For bounded intervals \([-1, 1]\). * Gauss-Hermite: For integrals over \((-\infty, \infty)\) with weight \(e^{-x^2}\). Perfect for Normal Distributions.

    Change of Variables¶

    Gaussian rules are defined on standard intervals (e.g., \([-1, 1]\)). To integrate over \([a, b]\), we use a linear change of variable \(x = \frac{b-a}{2}\xi + \frac{a+b}{2}\). This scales the weights by \(\frac{b-a}{2}\) (the Jacobian of the transformation).

    Derivation of Simpson's Rule¶

    Figure: Quadrature error falling with the number of nodes.. Simpson's rule approximates \(f(x)\) with a quadratic \(P(x) = Ax^2 + Bx + C\) passing through \(-h, 0, h\). Integrating \(P(x)\) from \(-h\) to \(h\): \(\int_{-h}^h (Ax^2 + Bx + C) dx = [\frac{Ax^3}{3} + \frac{Bx^2}{2} + Cx]_{-h}^h = \frac{2Ah^3}{3} + 2Ch\) Solving for \(A, B, C\) in terms of \(f(-h), f(0), f(h)\), we get the weights \(\frac{h}{3}[1, 4, 1]\).

    def f(x): return np.exp(x)
a, b = 0, 1
true_val = np.e - 1

N = 5
x = np.linspace(a, b, N)
y = f(x)

# 1. Trapezoidal
res_trap = trapezoid(y, x)

# 2. Gauss-Legendre
# Get nodes/weights for interval [-1, 1]
nodes, weights = roots_legendre(N)
# Transform to [a, b]
nodes_trans = 0.5 * (b - a) * nodes + 0.5 * (b + a)
weights_trans = 0.5 * (b - a) * weights
res_gauss = np.sum(weights_trans * f(nodes_trans))

print(f"True Value:     {true_val:.8f}")
print(f"Trapezoidal:    {res_trap:.8f} (Error: {abs(res_trap - true_val):.2e})")
print(f"Gaussian Quad:  {res_gauss:.8f} (Error: {abs(res_gauss - true_val):.2e})")
print("Observation: Gaussian Quadrature is phenomenally accurate for smooth functions.")

    Application: Expected Utility with Normal Shocks¶

    For a function \(u: \mathbb{R} \to \mathbb{R}\) with an integrable Gaussian expectation, first consider \(c = \mu + \sigma\,\epsilon\) and \(\epsilon \sim N(0, 1)\). Start from the definition of expectation under the standard normal density \(\phi(\epsilon) = \frac{1}{\sqrt{2\pi}} e^{-\epsilon^2/2}\): $$ E[u©] = \int_{-\infty}^{\infty} u(\mu + \sigma\epsilon)\, \frac{1}{\sqrt{2\pi}}\, e^{-\epsilon^2/2}\, d\epsilon. $$ Now substitute \(\epsilon = \sqrt{2}\,x\), so \(d\epsilon = \sqrt{2}\,dx\) and \(\epsilon^2/2 = x^2\): $$ E[u©] = \int_{-\infty}^{\infty} u(\mu + \sigma\sqrt{2}\,x)\, \frac{1}{\sqrt{2\pi}}\, e^{-x^2} \sqrt{2}\,dx = \frac{1}{\sqrt{\pi}} \int_{-\infty}^{\infty} u(\mu + \sigma\sqrt{2}\,x)\, e^{-x^2}\, dx. $$ The integrand is now in Gauss–Hermite form \(\int e^{-x^2} g(x)\,dx\) (with \(g\) absorbing every factor except \(e^{-x^2}\)), which is exactly what Gauss–Hermite nodes and weights evaluate efficiently. We use Gauss-Hermite quadrature.

    CRRA utility requires positive consumption, so the example below instead sets \(c=\exp(\mu+\sigma\epsilon)\). Here \(\mu\) and \(\sigma\) describe log consumption. An additive normal specification assigns positive probability to nonpositive consumption and, for \(u(c)=-1/c\), has a singularity at zero; a finite-looking quadrature answer would not establish a valid expected utility. For lognormal consumption and \(\gamma=2\), the analytic benchmark is \(E[u(c)]=-\exp(-\mu+\sigma^2/2)\).

    def utility(c):
    # CRRA utility
    gamma = 2.0
    return (c**(1-gamma))/(1-gamma)

mu, sigma = np.log(10.0), 0.2  # mean and standard deviation of log consumption
N_nodes = 7

# Get Gauss-Hermite nodes/weights
gh_nodes, gh_weights = roots_hermite(N_nodes)

# Transform Gaussian log consumption to positive consumption.
c_nodes = np.exp(mu + np.sqrt(2) * sigma * gh_nodes)

# Compute expectation: (1/sqrt(pi)) * sum(w * u(c))
expected_u = (1 / np.sqrt(np.pi)) * np.sum(gh_weights * utility(c_nodes))

# Compare with Monte Carlo (benchmark)
mc_draws = rng.lognormal(mu, sigma, size=1_000_000)
mc_u = np.mean(utility(mc_draws))

analytic_u = -np.exp(-mu + sigma**2 / 2)
print(f"Expected Utility (analytic lognormal): {analytic_u:.6f}")
print(f"Expected Utility (Gauss-Hermite, N={N_nodes}): {expected_u:.6f}")
print(f"Expected Utility (Monte Carlo, N=1M):    {mc_u:.6f}")

    2. Monte Carlo Integration¶

    When dimension \(D\) is high (e.g., 50 assets in a portfolio), grid methods fail (\(N^D\)). Monte Carlo relies on the Law of Large Numbers. $$ E[f(X)] \approx \frac{1}{N} \sum_{i=1}^N f(x_i) $$ Error scales as \(1/\sqrt{N}\), independent of dimension.

    Standard Error Derivation¶

    Let \(\hat{\mu} = \frac{1}{N} \sum f(x_i)\). The variance of this estimator is \(Var(\hat{\mu}) = \frac{1}{N^2} \sum Var(f(X)) = \frac{\sigma^2}{N}\). The standard error is \(\frac{\sigma}{\sqrt{N}}\). To halve the error, you need \(4\times\) the samples.

    Variance Reduction¶

    Standard MC is slow. We can speed it up: * Antithetic Variates: If you draw \(\epsilon\), also use \(-\epsilon\). This cancels out odd moments. * Control Variates: Use a known correlated variable to adjust the estimate.

    Quasi-Monte Carlo (QMC)¶

    Random numbers clump together. Low-discrepancy sequences (like Sobol or Halton) fill space more evenly. The Koksma-Hlawka inequality states that QMC error is \(O(\frac{(\log N)^D}{N})\), which is asymptotically faster than MC's \(O(\frac{1}{\sqrt{N}})\).

    Example: Generating a Halton Sequence To generate a Halton sequence in 1D with base \(b\), we reverse the digits of the index \(n\) in base \(b\). E.g., for base 2: \(1=1_2 \to 0.1_2=0.5\), \(2=10_2 \to 0.01_2=0.25\), \(3=11_2 \to 0.11_2=0.75\). This fills the gaps sequentially.

    Verbatim Walkthrough: The Race to Zero Error¶

    Let's watch the race below, which is staged in one dimension. The theory block explains how the verdict flips as the dimension grows.

    Theory: * Tensor-product Simpson's Rule Error: \(O(N^{-4/D})\) when \(N\) counts the total function evaluations in \(D\) dimensions (gets terrible as \(D\) grows). * Monte Carlo Error: \(O(N^{-1/2})\), independent of dimension (slow but steady).

    Notice that for \(D=1\) below, Simpson's error collapses far faster than MC's. In \(D=10\), a comparably accurate tensor-grid Simpson rule would need roughly \(N^{10}\) evaluations while MC keeps its dimension-free \(N^{-1/2}\) rate.

    # Comparing Convergence Rates
# Integrand: exp(x) on [0, 1]. Deliberately NOT a polynomial - Simpson's
# rule is exact up to degree 3, so x^2 would show zero error at every N.
N_values = [100, 1000, 10000, 100000]
mc_errors = []
quad_errors = []

# True integral of e^x from 0 to 1 is e - 1
true_val = np.e - 1

print(f"{'N':<10} | {'MC Error':<15} | {'Simpson Error':<15}")
print("-"*45)

for N in N_values:
    # Monte Carlo
    x_mc = rng.random(N)
    est_mc = np.mean(np.exp(x_mc))
    mc_errors.append(abs(est_mc - true_val))

    # Simpson's Rule (1D)
    x_quad = np.linspace(0, 1, N)
    y_quad = np.exp(x_quad)
    est_quad = simpson(y_quad, x_quad)
    quad_errors.append(abs(est_quad - true_val))

    print(f"{N:<10} | {mc_errors[-1]:<15.2e} | {quad_errors[-1]:<15.2e}")

print("Observation: In 1D, Simpson wins easily. Try imagining this in 10D!")

    Markov Chain Monte Carlo (MCMC)¶

    In Bayesian statistics, we often need to integrate over a posterior distribution \(P(\theta | Data)\) that is known only up to a constant. We can't sample from it directly. Metropolis-Hastings is an algorithm that constructs a Markov Chain whose stationary distribution is the target posterior. 1. Start at \(\theta_t\). 2. Propose \(\theta_{new} \sim Q(\theta | \theta_t)\). 3. Accept \(\theta_{new}\) with probability \(\alpha = \min(1, \frac{P(\theta_{new}) Q(\theta_t|\theta_{new})}{P(\theta_t) Q(\theta_{new}|\theta_t)})\). * Intuition for \(\alpha\): If the new point is more likely (\(P(\theta_{new}) > P(\theta_t)\)), we accept it. If less likely, we might still accept it to explore. The \(Q\) terms correct for asymmetric proposal distributions. 4. Repeat. The samples \(\theta_1, \dots, \theta_N\) eventually come from \(P(\theta)\).

    # --- Bayesian Inference via Metropolis-Hastings ---
# Goal: Estimate the mean 'mu' of a Normal dist given data, assuming known sigma=1
# Prior: mu ~ Normal(0, 10)
# Likelihood: data ~ Normal(mu, 1)

data = np.array([2.5, 3.0, 3.5, 4.0])

def log_prior(mu):
    return norm.logpdf(mu, loc=0, scale=10)

def log_likelihood(mu, data):
    return np.sum(norm.logpdf(data, loc=mu, scale=1))

def log_posterior(mu, data):
    return log_prior(mu) + log_likelihood(mu, data)

# MCMC Sampler
n_samples = 5000
samples = np.zeros(n_samples)
current_mu = 0.0 # Initial guess
accepted = 0

for i in range(n_samples):
    # Propose new mu: random walk
    proposal = current_mu + rng.normal(0, 0.5)

    # Calculate acceptance probability (in log space)
    log_alpha = log_posterior(proposal, data) - log_posterior(current_mu, data)

    # Accept/Reject
    if np.log(rng.random()) < log_alpha:
        current_mu = proposal
        accepted += 1

    samples[i] = current_mu

print(f"MCMC Acceptance Rate: {accepted/n_samples:.2%}")
print(f"Estimated Mean: {np.mean(samples[1000:]):.4f} (True Posterior Mean approx {np.mean(data):.4f})")

# Plot
plt.figure(figsize=(8, 5))
sns.histplot(samples[1000:], stat='density', kde=True, label='Posterior (MCMC)')
plt.axvline(np.mean(data), color='r', linestyle='--', label='Sample Mean')
plt.title(r"Bayesian Posterior for $\mu$ via MCMC")
plt.legend()
plt.show()

    Application: Pricing a Call Option¶

    Price of a Call Option \(C = E[e^{-rT} \max(S_T - K, 0)]\). Assume Geometric Brownian Motion for stock price \(S_T\).

    S0 = 100
K = 105
T = 1.0
r = 0.05
sigma = 0.2
N_sims = 100_000

# 1. Standard Monte Carlo
z = rng.standard_normal(N_sims)
ST = S0 * np.exp((r - 0.5*sigma**2)*T + sigma*np.sqrt(T)*z)
payoff = np.maximum(ST - K, 0)
price_mc = np.exp(-r*T) * np.mean(payoff)

# 2. Antithetic Variates (Variance Reduction)
# Use z and -z
ST_plus = S0 * np.exp((r - 0.5*sigma**2)*T + sigma*np.sqrt(T)*z)
ST_minus = S0 * np.exp((r - 0.5*sigma**2)*T + sigma*np.sqrt(T)*(-z))

payoff_av = 0.5 * (np.maximum(ST_plus - K, 0) + np.maximum(ST_minus - K, 0))
price_av = np.exp(-r*T) * np.mean(payoff_av)

# Calculate Variances
var_mc = np.var(np.exp(-r*T) * payoff)
var_av = np.var(np.exp(-r*T) * payoff_av)

print(f"Price (Standard MC): {price_mc:.4f} (Var: {var_mc:.4f})")
print(f"Price (Antithetic):  {price_av:.4f} (Var: {var_av:.4f})")
print(f"Variance Reduction:  {100*(1 - var_av/var_mc):.1f}%")

    Assumptions Behind the Quadrature Rules¶

    The convergence statements in this notebook assume the integrand is finite on the integration domain and has the smoothness required by the chosen rule. Gaussian quadrature additionally assumes the weighted moments exist; Monte Carlo estimators require an integrable target and finite variance for the usual \(N^{-1/2}\) error characterization. Heavy tails or singular endpoints therefore require transformation, specialized weights, or robust simulation rather than blind application of a textbook rule.

    Key Equations¶

    • Generic expectation: \(\mathbb{E}[g(X)] = \int g(x) f(x)\,dx\).
    • Gauss quadrature: \(\int_a^b f(x)w(x)\,dx \approx \sum_{i=1}^{n} w_i f(x_i)\).
    • Monte Carlo: \(\hat I_N = N^{-1}\sum_{i=1}^N g(X_i)\) with sampling error \(O_p(N^{-1/2})\) under finite variance.
    • Gauss-Hermite mapping: use Hermite nodes and weights after transforming a Gaussian expectation to the \(e^{-x^2}\) weight.

    Summary¶

    Key Takeaways: * Smooth & Low Dim? Use Gaussian Quadrature (Legendre for bounded, Hermite for Normal). Hard to beat when the integrand is genuinely smooth. * Rough or High Dim? Use Monte Carlo. It's slow but reliable. * Variance Reduction: Antithetic Variates are nearly free and cut variance for payoffs that are monotone in the underlying shock - but measure the reduction instead of assuming it, since non-monotone payoffs can backfire.
