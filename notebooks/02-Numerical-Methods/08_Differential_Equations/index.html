    08 Differential Equations¶

    The Lens: The Law of Motion¶

    What problem are we solving?
    Economic systems evolve over time. * Growth: \(\dot{k}(t) = i(t) - \delta k(t)\) * Demographics: \(\dot{N}(t) = n N(t)\) * Asset Prices: \(dP/P = \mu dt + \sigma dZ\) (Stochastic)

    These are Differential Equations. They describe the instantaneous change. To see the future, we must "integrate" these equations.

    Why this method?
    We need to step forward in time numerically. * Euler Method: Simple, linear projection. Unstable for large steps. * Runge-Kutta (RK45): The industry standard. Samples slope at multiple points for high accuracy. * Shooting Method: Used for Boundary Value Problems (like finding the saddle path to a steady state). * Implicit Methods (Radau/BDF): Essential for stiff systems where time scales vary wildly.

    Stiffness and Implicit Methods¶

    A system is stiff if it has both very fast and very slow dynamics (e.g., asset prices move instantly, capital moves slowly). Explicit methods like Euler or RK45 are forced to take tiny steps to track the fast dynamics, making them incredibly slow. Implicit methods (like Radau or BDF in solve_ivp) solve a system of equations at each step to ensure stability, allowing for much larger time steps.

    Learning Objectives¶

    By the end of this notebook, you will be able to: 1. Analyze stability using Phase Diagrams and Eigenvalues. 2. Solve Initial Value Problems (IVPs) using solve_ivp. 3. Solve Boundary Value Problems (BVPs) using the Shooting Method AND Relaxation (solve_bvp). 4. Simulate the Ramsey-Cass-Koopmans growth model.

    1. Theory of Dynamic Systems¶

    1.1 Phase Diagrams¶

    For a 2D system, we visualize dynamics by plotting Nullclines (where \(\dot{x}=0\) or \(\dot{y}=0\)). Their intersection is the Steady State.

    1.2 Stability Analysis¶

    Linearize the system around the steady state: \(\dot{z} \approx J(\mathbf{z}^*) (\mathbf{z} - \mathbf{z}^*)\). The eigenvalues of the Jacobian \(J\) tell the story: * Sink: Real parts \(< 0\). Stable. * Source: Real parts \(> 0\). Unstable. * Saddle: Mixed signs. Unique stable path (Saddle Path).

    The Stable Manifold Theorem: If the linearized system has a saddle point (e.g., 1 negative eigenvalue, 1 positive), then in the original non-linear system, there exists a unique curve (manifold) passing through the steady state such that trajectories starting on it converge to the steady state. All other trajectories diverge. This curve is tangent to the eigenvector associated with the negative eigenvalue.

    Visualizing Stability via Trace and Determinant¶

    For a 2D system with Jacobian \(J\), let \(T = \text{tr}(J)\) and \(D = \det(J)\). The eigenvalues are \(\lambda = \frac{T \pm \sqrt{T^2 - 4D}}{2}\). * \(D < 0\): Saddle Point (Real eigenvalues, opposite signs). * \(D > 0, T < 0\): Sink (Stable). If \(T^2 < 4D\), it's a Spiral Sink. * \(D > 0, T > 0\): Source (Unstable).

    1.3 Bifurcation Theory¶

    Figure: A saddle-node bifurcation in a one-dimensional system.. Dynamic systems depend on parameters. As a parameter changes, the stability or number of fixed points can change. This is a Bifurcation. Example: Saddle-Node Bifurcation (\(\dot{x} = r + x^2\)) * \(r < 0\): Two fixed points (Stable \(-\sqrt{-r}\), Unstable \(+\sqrt{-r}\)): here \(f'(x^*) = 2x^*\) is negative at the left branch and positive at the right one. * \(r = 0\): One semi-stable fixed point (\(x=0\)). * \(r > 0\): No fixed points (Bottleneck). At \(r=0\), the two fixed points collide and annihilate. This condition is characterized by \(f(x^*) = 0\) AND \(f'(x^*) = 0\).

    # --- Visualizing Bifurcation ---
r_vals = np.linspace(-2, 1, 100)
# Fixed points: x* = +/- sqrt(-r) for r < 0
x_stable = -np.sqrt(-r_vals[r_vals <= 0])
x_unstable = np.sqrt(-r_vals[r_vals <= 0])

plt.figure(figsize=(8, 5))
plt.plot(r_vals[r_vals <= 0], x_stable, 'b-', label='Stable Node')
plt.plot(r_vals[r_vals <= 0], x_unstable, 'r--', label='Unstable Node')
plt.axvline(0, color='k', linestyle=':', label='Bifurcation Point (r=0)')
plt.title('Saddle-Node Bifurcation Diagram')
plt.xlabel('Parameter r')
plt.ylabel('Fixed Point x*')
plt.legend()
plt.grid(True)
plt.show()

    # Example: Predatory-Prey (Lotka-Volterra)
# dx/dt = alpha*x - beta*x*y
# dy/dt = delta*x*y - gamma*y

def lotka_volterra(t, z, alpha, beta, delta, gamma):
    x, y = z
    dxdt = alpha*x - beta*x*y
    dydt = delta*x*y - gamma*y
    return [dxdt, dydt]

params = (1.1, 0.4, 0.1, 0.4)
t_span = [0, 50]
z0 = [10, 10]

# Tight tolerance: Lotka-Volterra orbits are closed, and the default
# rtol=1e-3 lets the numerical cycle visibly spiral instead.
sol = solve_ivp(lotka_volterra, t_span, z0, args=params,
                dense_output=True, rtol=1e-8, atol=1e-10)

t = np.linspace(0, 50, 300)
z = sol.sol(t)

fig, ax = plt.subplots(1, 2, figsize=(12, 5))

# Time Series
ax[0].plot(t, z[0], label='Prey')
ax[0].plot(t, z[1], label='Predator')
ax[0].set_title("Time Series")
ax[0].legend()

# Phase Diagram
ax[1].plot(z[0], z[1])
ax[1].set_title("Phase Portrait (Cycles)")
ax[1].set_xlabel("Prey")
ax[1].set_ylabel("Predator")
plt.show()

    2. The Ramsey-Cass-Koopmans (RCK) Model¶

    Figure: Phase diagram of the Ramsey-Cass-Koopmans system..

    The central model of neoclassical growth. Households optimize lifetime utility.

    System: 1. \(\dot{k} = k^\alpha - (n+g+\delta)k - c\) (Resource Constraint) 2. \(\frac{\dot{c}}{c} = \frac{1}{\theta} (\alpha k^{\alpha-1} - \delta - \rho - \theta g)\) (Euler Equation)

    Linearization: Both state variables are positive scalars, so the phase space is \((k, c) \in \mathbb{R}_{++}^2\) and the linearized dynamics live in \(\mathbb{R}^{2 \times 2}\). The Jacobian \(J\) evaluated at the steady state \((k^*, c^*)\) is: $$ J = \begin{bmatrix} \frac{\partial \dot{k}}{\partial k} & \frac{\partial \dot{k}}{\partial c} \ \frac{\partial \dot{c}}{\partial k} & \frac{\partial \dot{c}}{\partial c} \end{bmatrix} = \begin{bmatrix} \rho+\theta g-n-g & -1 \ \frac{c}{\theta} \alpha (\alpha-1) (k^) $$ The determinant is negative (} & 0 \end{bmatrix\(\det\,J = \frac{c^*}{\theta}\alpha(\alpha-1)(k^*)^{\alpha-2} < 0\) because \(\alpha < 1\)), so the eigenvalues are real with opposite signs regardless of the trace; the saddle path is confirmed. (The trace is \(\rho + \theta g - n - g\), which equals \(\rho > 0\) under this notebook's calibration.)

    This system has a Saddle Point. Given \(k_0\), there is a unique initial consumption \(c_0\) that puts us on the path to the steady state.

    # Parameters
p = {
    'alpha': 0.3, 'n': 0.01, 'g': 0.01, 'delta': 0.05,
    'rho': 0.02, 'theta': 2.0
}

# Steady State
k_star = (p['alpha'] / (p['delta'] + p['rho'] + p['theta']*p['g']))**(1/(1-p['alpha']))
c_star = k_star**p['alpha'] - (p['n'] + p['g'] + p['delta'])*k_star

print(f"Steady State: k*={k_star:.2f}, c*={c_star:.2f}")

# ODE System
def rck_system(t, z, p):
    k, c = z
    if k <= 0:
        # Guard for the shooting search: k**alpha and k**(alpha-1)
        # produce NaNs for k < 0, so freeze the motion there instead.
        # (Must come BEFORE any fractional powers are evaluated.)
        return [0.0, c]
    dk = k**p['alpha'] - (p['n'] + p['g'] + p['delta'])*k - c
    mpk = p['alpha'] * k**(p['alpha']-1)
    dc = (c / p['theta']) * (mpk - p['delta'] - p['rho'] - p['theta']*p['g'])
    return [dk, dc]

    3. The Shooting Method¶

    We have \(k_0\). We need to find \(c_0\). This is a Boundary Value Problem (BVP) masquerading as an IVP.

    Verbatim Walkthrough: Why is it called "Shooting"?¶

    Imagine you are trying to hit a target (the steady state \(k^*\)) with a cannon. You know where you are standing (\(k_0\)), but you don't know the angle (\(c_0\)) to aim.

    1. Aim: Guess an initial consumption \(c_0\).
    2. Fire: Simulate the economy forward in time using solve_ivp.
    3. Miss: Check where you landed. Did you end up with too much capital (\(k_T > k^*\)) or too little (\(k_T < k^*\))?
    4. Adjust: If you overshot, lower your aim (consume more today). If you undershot, raise your aim.

    Mathematically, we are finding the root of the error function \(E(c_0) = k(T|c_0) - k^*\).

    Demonstration: The Stiffness Trap¶

    Consider a simple stiff system: \(\dot{y} = -1000y + 1000\sin(t)\). The decay is extremely fast (\(e^{-1000t}\)), but the driving force is slow (\(\sin t\)). Explicit solvers like RK45 are stability-limited to steps of order \(|\lambda|^{-1}\) (about 0.001 here) even though the solution looks smooth. Implicit solvers (Radau) choose steps based on accuracy alone and stay stable at any step size. The cell below runs the race.

    Economic Analogy: Asset prices adjust instantly (fast), while capital accumulates slowly (slow). This makes many macro models stiff.

    Symplectic Integrators¶

    For Hamiltonian systems (where energy is conserved, like planetary motion or utility maximization over infinite horizons), standard methods like Runge-Kutta slowly dissipate energy. Symplectic Integrators preserve the geometric structure of the system (volume in phase space), ensuring stability over extremely long simulation times. While RCK has dissipation (discounting), these methods are crucial for RBC models without friction.

    Algorithm: 1. Guess \(c_0\). 2. Simulate forward to time \(T\). 3. Check error: \(E(c_0) = k(T) - k^*\). 4. Use a root finder to adjust \(c_0\) until \(E(c_0) = 0\) (or close enough).

    # Demonstration: the stiffness trap in numbers
def stiff_rhs(t, y):
    return -1000 * (y - np.sin(t))

t_span = [0.0, 5.0]
y0 = [0.0]

sol_rk45 = solve_ivp(stiff_rhs, t_span, y0, method='RK45',
                     rtol=1e-6, atol=1e-9)
sol_radau = solve_ivp(stiff_rhs, t_span, y0, method='Radau',
                      rtol=1e-6, atol=1e-9)

print(f"RK45  (explicit): {len(sol_rk45.t)} internal time points")
print(f"Radau (implicit): {len(sol_radau.t)} internal time points")
print("Both track the same smooth solution; the explicit solver crawls"
      " because stability, not accuracy, caps its step size.")

    def shooting_objective(c0_guess, k0, T, p, k_target):
    # Solve IVP
    sol = solve_ivp(rck_system, [0, T], [k0, c0_guess], args=(p,), rtol=1e-6)
    k_T = sol.y[0][-1]
    # Root condition: land on the target capital stock. Only the c0 on
    # the saddle path survives to T without diverging away from k_star.
    return k_T - k_target

k0 = 0.5 * k_star
T_horizon = 100

# Find c0 that puts us on the path
# Bounds for c0: [0, max_possible_consumption]
c0_optimal = brentq(shooting_objective, 0.01, 2.0, args=(k0, T_horizon, p, k_star))

print(f"Optimal Initial Consumption c0: {c0_optimal:.4f}")

# Simulate the optimal path
sol_opt = solve_ivp(rck_system, [0, T_horizon], [k0, c0_optimal], args=(p,),
                    dense_output=True, rtol=1e-6)  # match the shooting tolerance
t_path = np.linspace(0, T_horizon, 200)
z_path = sol_opt.sol(t_path)

plt.figure(figsize=(8, 6))
plt.plot(z_path[0], z_path[1], 'b-', label='Saddle Path')
plt.plot(k_star, c_star, 'ro', label='Steady State')
plt.xlabel("Capital (k)")
plt.ylabel("Consumption (c)")
plt.title("RCK Model Phase Diagram: The Saddle Path")
plt.legend()
plt.show()

    4. Robust BVP Solving with solve_bvp¶

    The shooting method can be unstable because the unstable manifold (any path not exactly on the saddle) diverges exponentially. A more robust approach solves for the entire path simultaneously. scipy.integrate.solve_bvp uses fourth-order collocation with residual control and an adaptive mesh, rather than a finite-difference shooting scheme.

    # solve_bvp requires:
# 1. Function f(t, y)
# 2. Boundary conditions function bc(y(a), y(b))
# 3. Initial mesh of time points
# 4. Initial guess for y at those points

def bvp_system(t, z, p=p):
    # Default argument captures the parameter dict defined above;
    # solve_bvp calls f(t, y) with no extra arguments.
    k, c = z
    dk = k**p['alpha'] - (p['n'] + p['g'] + p['delta'])*k - c
    mpk = p['alpha'] * k**(p['alpha']-1)
    dc = (c / p['theta']) * (mpk - p['delta'] - p['rho'] - p['theta']*p['g'])
    return np.vstack((dk, dc))

def bc(ya, yb, p=p):
    # ya is y(0), yb is y(T)
    # Boundary Conditions:
    # 1. k(0) = k0
    # 2. k(T) = k_star (Approximate infinite horizon with large T)
    return np.array([ya[0] - k0, yb[0] - k_star])

# Initial Mesh
x_mesh = np.linspace(0, T_horizon, 50)
# Initial Guess: Linear interpolation between start and steady state
y_guess = np.zeros((2, x_mesh.size))
y_guess[0, :] = np.linspace(k0, k_star, x_mesh.size)
y_guess[1, :] = np.linspace(0.5, c_star, x_mesh.size)

# Solve
res_bvp = solve_bvp(bvp_system, bc, x_mesh, y_guess)

if res_bvp.success:
    print("solve_bvp converged!")
    # Plot comparison
    plt.figure(figsize=(8, 6))
    plt.plot(z_path[0], z_path[1], 'b-', label='Shooting Method')
    plt.plot(res_bvp.y[0], res_bvp.y[1], 'g--', label='Relaxation (solve_bvp)', linewidth=2)
    plt.plot(k_star, c_star, 'ro')
    plt.legend()
    plt.title("Shooting vs. Relaxation")
    plt.show()
else:
    print("solve_bvp failed.")

    Summary¶

    Key Takeaways: * Phase Diagrams: Essential for qualitative understanding before coding. * IVP vs BVP: Growth models are usually BVPs (Start at \(k_0\), end at \(k^*\)). * Shooting Method: Converts a BVP into a root-finding problem over an IVP. * Relaxation (solve_bvp): More robust for unstable systems than shooting.

    Common Pitfalls in This Lecture

    • Explicit solvers on stiff systems. RCK-style models with fast and slow eigenvalues force explicit Runge-Kutta to crawl with microscopic steps. Detect stiffness (solver step-size warnings) and switch to implicit Radau or BDF — often orders of magnitude faster and stable.
    • Loose tolerances. rtol=1e-3 defaults can bend phase diagrams qualitatively: spirals become nodes, saddle paths drift. Tighten rtol/atol until the trajectory stops moving, especially before teaching stability from a simulation plot.

    3. Challenge: Reverse Shooting¶

    The shooting method is unstable for long horizons because the unstable manifold diverges. Reverse Shooting (time reversal) turns the unstable manifold into a stable one. Simulate the RCK model backwards starting from near the steady state \((k^* - \epsilon, c^* - \delta)\) to trace out the saddle path more robustly.

    Failure analysis (Challenge): solve_ivp with RK45 takes minutes on the RCK system and warns about step-size, while a larger step makes the trajectory blow up. Diagnose stiffness from the eigenvalue spread, repair with an implicit solver (Radau/BDF), and compare step counts and accuracy against the explicit run.
