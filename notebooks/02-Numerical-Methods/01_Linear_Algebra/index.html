    01 Linear Algebra¶

    The Lens: The Engine of Computational Economics¶

    What problem are we solving?
    Economics is the science of interconnected systems. A change in the Fed funds rate ripples through bond markets, mortgage rates, housing demand, and construction employment. A tariff on steel alters input costs for automakers, construction firms, and appliance manufacturers. To model these systems, we need a language that can handle simultaneity and dimensionality. Single equations are insufficient; we need systems of equations.

    Why this method?
    Linear Algebra is that language. It provides the geometry and arithmetic for high-dimensional spaces. In computational economics, matrices are not just abstract arrays of numbers; they are the gears of our models: * The Jacobian Matrix encodes how a system evolves dynamically near a steady state. * The Hessian Matrix tells us if an optimal policy is a maximum or a minimum. * The Markov Matrix describes how agents move between states (e.g., employment to unemployment) over time.

    This notebook moves beyond the textbook definitions to focus on the computational reality of linear algebra: numerical stability, the cost of inversion, and the power of decompositions like SVD.

    Learning Objectives¶

    By the end of this notebook, you will be able to: 1. Visualize linear transformations and understand the geometric meaning of determinants and eigenvalues. 2. Implement efficient and stable solutions to linear systems using scipy.linalg (avoiding explicit matrix inversion). 3. Diagnose ill-conditioned problems using the condition number. 4. Apply the Singular Value Decomposition (SVD) for dimensionality reduction (PCA). 5. Utilize sparse matrices to handle large-scale economic networks efficiently.

    Prerequisites¶

    • 01-Foundations/12_NumPy.ipynb: Familiarity with NumPy array creation and broadcasting.

    Historical Context — Turing and Wilkinson make elimination trustworthy (1948–1961). Alan Turing's 1948 paper on rounding errors introduced conditioning and analyzed Gaussian elimination; James Wilkinson at NPL then built backward error analysis, explaining why pivoted elimination is reliable. EISPACK and LINPACK (1970s) encoded these results, LAPACK (1992) refactored them for caches — numpy.linalg calls their descendants today.

    1. Vector Spaces, Subspaces, and Bases¶

    A vector space is a collection of objects called vectors, which can be added together and multiplied by scalars. The familiar n-dimensional real space, \(\mathbb{R}^n\), is the canonical example in economics.

    A subspace is a subset of a vector space that is itself a vector space. Crucially, it must contain the zero vector and be closed under vector addition and scalar multiplication.

    Key Concepts¶

    • Linear Independence: A set of vectors \(\{v_1, ..., v_k\}\) is linearly independent if no vector in the set can be written as a linear combination of the others.
    • Span: The span of a set of vectors is the set of all possible linear combinations of those vectors.
    • Basis: A basis is a set of linearly independent vectors that span the space. It provides a unique coordinate system.
    • Dimension: The number of vectors in a basis.

    Inner Products, Norms, and Angles¶

    Vector spaces often come with a notion of geometry defined by the Inner Product (Dot Product): \(x \cdot y = \sum x_i y_i\). This induces: * Norm (Length): \(||x|| = \sqrt{x \cdot x}\) * Angle: \(\cos \theta = \frac{x \cdot y}{||x|| \cdot ||y||}\). For nonconstant data vectors, Pearson correlation is the cosine of the angle between their mean-centered versions. Orthogonal raw vectors need not be uncorrelated.

    The Four Fundamental Subspaces¶

    For any \(m \times n\) matrix \(A\), four fundamental subspaces describe its structure. The Fundamental Theorem of Linear Algebra connects their dimensions:

    1. Column Space, \(C(A)\): The span of the columns of \(A\). Dimension = \(r\) (rank).
    2. Row Space, \(C(A^T)\): The span of the rows of \(A\). Dimension = \(r\).
    3. Null Space, \(N(A)\): Vectors \(x\) such that \(Ax = 0\). Dimension = \(n-r\).
    4. Left Null Space, \(N(A^T)\): Vectors \(y\) such that \(A^T y = 0\). Dimension = \(m-r\).

    Orthogonality: \(C(A^T) \perp N(A)\) and \(C(A) \perp N(A^T)\).

    Figure: The Big Picture of Linear Algebra (Strang). The Null Space is orthogonal to the Row Space.

    Application: Markov Chains and Steady States¶

    Linear Algebra provides a direct way to solve for the long-run equilibrium of a system. Consider a labor market where agents move between Employment (E) and Unemployment (U).

    Let \(x_t = [E_t, U_t]^T\). The dynamics are \(x_{t+1} = P^T x_t\), where \(P\) is the transition matrix. A steady state \(\pi\) satisfies \(\pi = P^T \pi\). This is an eigenvector problem: \(\pi\) is the eigenvector of \(P^T\) associated with eigenvalue \(\lambda=1\). The Perron-Frobenius Theorem guarantees that for a positive transition matrix, this eigenvector exists, is unique (up to scaling), and has positive entries.

    # Transition Matrix P (Rows sum to 1)
#        E    U
# E [0.95, 0.05]  (5% separation rate)
# U [0.40, 0.60]  (40% finding rate)
P = np.array([[0.95, 0.05],
              [0.40, 0.60]])

# We need to solve (P.T - I) * pi = 0
# Or find the eigenvector of P.T with eigenvalue 1
evals, evecs = linalg.eig(P.T)

# Find the index of the eigenvalue close to 1
idx = np.argmin(np.abs(evals - 1.0))
pi = np.real(evecs[:, idx])

# Normalize to sum to 1 (probability distribution)
pi = pi / np.sum(pi)

print(f"Steady State Unemployment Rate: {pi[1]:.2%}")
print(f"Steady State Employment Rate:   {pi[0]:.2%}")

    Special Matrices in Economics¶

    Certain matrix structures appear repeatedly in economic theory. Recognizing them allows us to use specialized, faster algorithms.

    1. Symmetric Matrices (\(A = A^T\)):

      • Where: Covariance matrices, Hessian matrices (second derivatives of utility/profit functions).
      • Property: All eigenvalues are real, and an orthonormal eigenbasis can be chosen. Eigenvectors for distinct eigenvalues are orthogonal.

    2. Positive Definite Matrices:

      • Where: A valid covariance matrix must be positive semi-definite. For a twice-differentiable unconstrained objective, a local minimum requires a positive semi-definite Hessian. At a stationary point, positive definiteness is sufficient for a strict local minimum, but not necessary: \(f(x)=x^4\) has a strict minimum with \(f^{\prime\prime}(0)=0\).
      • Definition: \(x^T A x > 0\) for all non-zero vectors \(x\).
      • Check: All eigenvalues are positive.

      Cholesky Decomposition: A symmetric positive-definite matrix \(A\) can be uniquely factored as \(A = L L^T\), where \(L\) is a lower triangular matrix with positive diagonal entries. This is essentially a "square root" of a matrix. * Application: Generating correlated random variables. If \(z \sim N(0, I)\), then \(x = Lz + \mu\) follows \(N(\mu, \Sigma)\) where \(\Sigma = LL^T\).

    3. Idempotent Matrices (\(P^2 = P\)):

      • Where: Projection matrices in OLS (the "Hat Matrix").
      • Property: Eigenvalues are either 0 or 1.

    4. Orthogonal Matrices (\(Q^T Q = I\)):

      • Where: Rotations, QR decomposition, SVD.
      • Property: Preserves length (\(||Qx|| = ||x||\)) and angles.

    2. Matrices as Linear Transformations¶

    A matrix \(A \in \mathbb{R}^{m \times n}\) represents a linear transformation mapping \(\mathbb{R}^n \to \mathbb{R}^m\). Geometrically, it distorts space: it can rotate, scale, shear, or project vectors.

    Figure: A linear transformation mapping a square to a parallelogram. The determinant of a square matrix, \(\det(A)\), measures the change in volume induced by the transformation. * If \(\det(A) = 2\), the transformation doubles the area (in 2D) or volume (in 3D) of any shape. * If \(\det(A) = 0\), the transformation squashes space into a lower dimension (e.g., a plane into a line). The matrix is singular (not invertible).

    3. Solving Systems of Linear Equations: Ax = b¶

    The problem Ax = b asks: "What vector x, when transformed by A, lands on b?"

    Best Practice: solve > inv¶

    In mathematical notation, we write \(x = A^{-1}b\). However, in numerical computing, you should almost never compute the inverse explicitly.

    Computing x = inv(A) @ b is: 1. Slower: Inverting a matrix is computationally more expensive than solving the system. 2. Less Accurate: It introduces more floating-point round-off error.

    Instead, use scipy.linalg.solve(A, b), which uses highly optimized decompositions (like LU factorization).

    N = 2000
A = rng.random((N, N))
b = rng.random(N)

print(f"Solving system of size {N}x{N}...")

# 1. Using solve (The Right Way)
start = time.time()
x_solve = linalg.solve(A, b)
t_solve = time.time() - start
print(f"`linalg.solve`: {t_solve:.4f} seconds")

# 2. Using inverse (The Wrong Way)
start = time.time()
x_inv = linalg.inv(A) @ b
t_inv = time.time() - start
print(f"`linalg.inv`:   {t_inv:.4f} seconds")

print(f"Speedup: {t_inv / t_solve:.2f}x")

# Accuracy: compare the two answers (both are close here on a well-conditioned
# random matrix, but inv() carries extra round-off and costs ~2x the flops)
r_solve = np.linalg.norm(A @ x_solve - b)
r_inv = np.linalg.norm(A @ x_inv - b)
print(f"Residual ||Ax-b|| via solve: {r_solve:.3e}")
print(f"Residual ||Ax-b|| via inv:   {r_inv:.3e}")
print(f"Max abs difference between the two solutions: {np.max(np.abs(x_solve - x_inv)):.3e}")

    Application: The Leontief Input-Output Model¶

    The Leontief model describes an economy where each sector requires inputs from other sectors to produce output. Let \(A\) be the technology matrix where \(A_{ij}\) is the input from sector \(i\) required to produce 1 unit of good \(j\). With \(n\) sectors, the dimensions are \(A \in \mathbb{R}^{n \times n}\) and \(x, d \in \mathbb{R}^n\), while \(I = I_n\) is the \(n \times n\) identity — so \((I - A)\) is square, and the system below has a unique solution whenever it is nonsingular. Let \(d\) be the vector of final demand. The total gross output \(x\) required is:

    \[ x = Ax + d \implies (I - A)x = d \]

    We need to solve this linear system for \(x\).

    Application: Ordinary Least Squares (OLS)¶

    In OLS, we want to find the vector \(\beta\) that minimizes the sum of squared residuals: \(||y - X\beta||^2\).

    Derivation of Normal Equations: 1. Objective: \(L(\beta) = (y - X\beta)^T (y - X\beta)\) 2. Expand: \(L(\beta) = y^T y - \beta^T X^T y - y^T X \beta + \beta^T X^T X \beta\) 3. Derivative w.r.t. \(\beta\): \(\nabla_\beta L = -2 X^T y + 2 X^T X \beta\) 4. Set to zero: \(X^T X \beta = X^T y\)

    Why is \(X^T X\) Symmetric Positive Semi-Definite? * Symmetric: \((X^T X)^T = X^T (X^T)^T = X^T X\). * Positive Semi-Definite: For any vector \(v\), \(v^T (X^T X) v = (Xv)^T (Xv) = ||Xv||^2 \ge 0\). This ensures the critical point is a minimum.

    # Technology Matrix (3 sectors: Ag, Manuf, Svcs)
# e.g., A[0,1] = 0.2 means Manuf needs 0.2 units from Ag per unit of output
A = np.array([[0.1, 0.2, 0.4],
              [0.5, 0.1, 0.3],
              [0.1, 0.6, 0.1]])

I = np.eye(3)
L = I - A # Leontief Matrix

# Scenario: Different final demands
d_scenario1 = np.array([100, 200, 500])

# Factorize L once (LU decomposition) to reuse for multiple solves
lu_piv = linalg.lu_factor(L)

x1 = linalg.lu_solve(lu_piv, d_scenario1)
print(f"Required Output (Scenario 1): {x1}")

    4. Stability and the Condition Number¶

    The condition number \(\kappa(A)\) measures how sensitive the solution \(x\) is to small changes in \(b\) or \(A\). $$ \kappa(A) = ||A|| \cdot ||A^{-1}|| $$

    • Well-conditioned (low \(\kappa\)): Small errors in inputs lead to small errors in outputs.
    • Ill-conditioned (high \(\kappa\)): Small errors can explode. This often happens in OLS when regressors are highly correlated (multicollinearity).
    n = 100
x1 = rng.standard_normal(n)
# Create x2 highly correlated with x1
x2 = 0.999 * x1 + 0.001 * rng.standard_normal(n)

X = np.c_[np.ones(n), x1, x2]

# Compute condition number of X'X
cond_num = np.linalg.cond(X.T @ X)
print(f"Condition Number of X'X: {cond_num:.2e}")
print("Interpretation: This extremely high value indicates severe multicollinearity.")
print("OLS estimates will be unstable.")

    5. Eigenvalues and System Dynamics¶

    An eigenvector \(v\) of \(A\) is a vector that doesn't change direction when transformed by \(A\); it is only scaled by its eigenvalue \(\lambda\): $$ Av = \lambda v $$

    Here \(A \in \mathbb{R}^{n \times n}\), each eigenvector satisfies \(v_i \in \mathbb{C}^n \setminus \{0\}\), and \(\lambda_i \in \mathbb{C}\). Eigenvalues govern the long-run behavior of dynamic systems \(x_{t+1} = Ax_t\). If \(A\) is diagonalizable over \(\mathbb{C}\), we can write \(A = V \Lambda V^{-1}\) with eigenvector columns \(V = [v_1, \dots, v_n]\) and \(\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_n)\), we get \(A^t = V \Lambda^t V^{-1}\), hence $$ x_t = A^t x_0 = V \Lambda^t V^{-1} x_0 = \sum_{i=1}^n c_i \lambda_i^{\,t} v_i, \qquad c = V^{-1} x_0 \in \mathbb{C}^n, $$ a weighted sum of eigenvectors whose coefficients are determined at \(t=0\). Real matrices can have complex eigenvectors; conjugate pairs combine to give real trajectories. If \(A\) is defective, use Jordan or Schur form instead; the strict spectral-radius stability criterion below still holds. * If all \(|\lambda_i| < 1\), the terms \(\lambda_i^t \to 0\), so the system is stable (converges to steady state). If anyklzzwxh:0132, that term grows exponentially, making the system unstable**. * If mid, it exhibits saddle-path stability: only specific initial conditions (where the coefficients \(c_i\) for unstable modes are zero) lead to convergence.

    Figure: Phase diagram showing stable, unstable, and saddle-path dynamics based on eigenvalues.

    Verbatim Walkthrough: Solving a 2x2 System¶

    Let's unpack exactly how this decomposition works with a concrete example. Consider the system: $$ \begin{bmatrix} x_{t+1} \ y_{t+1} \end{bmatrix} = \begin{bmatrix} 0.5 & 0.2 \ 0.2 & 0.5 \end{bmatrix} \begin{bmatrix} x_t \ y_t \end{bmatrix} $$

    Step 1: Find Eigenvalues. Solve \(\det(A - \lambda I) = 0\). $$ \det \begin{bmatrix} 0.5 - \lambda & 0.2 \ 0.2 & 0.5 - \lambda \end{bmatrix} = (0.5 - \lambda)^2 - 0.04 = 0 $$ $$ (0.5 - \lambda)^2 = 0.04 \implies 0.5 - \lambda = \pm 0.2 $$ $$ \lambda_1 = 0.7, \quad \lambda_2 = 0.3 $$ Both are less than 1, so the system is stable.

    Step 2: Find Eigenvectors. For \(\lambda_1 = 0.7\): \((A - 0.7I)v_1 = 0 \implies -0.2x + 0.2y = 0 \implies x=y\). So \(v_1 = [1, 1]^T\). For \(\lambda_2 = 0.3\): \((A - 0.3I)v_2 = 0 \implies 0.2x + 0.2y = 0 \implies x=-y\). So \(v_2 = [1, -1]^T\).

    Step 3: General Solution. Any initial state \([x_0, y_0]^T\) can be written as \(c_1 v_1 + c_2 v_2\). The state at time \(t\) is: $$ \begin{bmatrix} x_t \ y_t \end{bmatrix} = c_1 (0.7)^t \begin{bmatrix} 1 \ 1 \end{bmatrix} + c_2 (0.3)^t \begin{bmatrix} 1 \ -1 \end{bmatrix} $$ Since \(0.7^t \to 0\) and \(0.3^t \to 0\), both \(x_t\) and \(y_t\) converge to 0.

    This is the foundation of analyzing steady states in Macroeconomics (e.g., Blanchard-Kahn conditions).

    6. The Singular Value Decomposition (SVD)¶

    The SVD is the "Swiss Army Knife" of linear algebra. It factors any matrix \(A\) into: $$ A = U \Sigma V^T $$ where \(\Sigma\) contains the singular values \(\sigma_i\). These values represent the "energy" or importance of each dimension.

    Application: Image Compression¶

    We can approximate a matrix (an image) using only its largest singular values. This is a "low-rank approximation".

    Deep Intuition: SVD works because it finds the "best" basis to represent the data. \(V\) rotates the data so that the first axis points in the direction of maximum variance (principal component), the second axis in the next largest variance, etc. \(\Sigma\) tells us how much variance is in each direction. Dropping small \(\sigma_i\) is just denoising.

    Application: Principal Component Analysis (PCA)¶

    In economics, PCA is used to summarize complex data. For example, the Yield Curve (interest rates at different maturities) is driven by three main factors: 1. Level: All rates move up/down together (1st Principal Component). 2. Slope: Short vs Long term rates change (2nd PC). 3. Curvature: Medium term rates bulge (3rd PC).

    If \(X\) is our data matrix (centered), then the Right Singular Vectors (\(V\)) of \(X\) are exactly the Principal Components.

    # Load sample image
img = face(gray=True)
img = img[::2, ::2] # Downsample for speed

# Compute SVD
U, s, Vt = linalg.svd(img, full_matrices=False)

def compress(k: int, U, s, Vt):
    """Reconstruct image using top k singular values."""
    S_k = np.diag(s[:k])
    return U[:, :k] @ S_k @ Vt[:k, :]

# Visualize
k_values = [5, 20, 50, 100]
fig, axes = plt.subplots(1, len(k_values)+1, figsize=(15, 4))

axes[0].imshow(img, cmap='gray')
axes[0].set_title("Original")
axes[0].axis('off')

for i, k in enumerate(k_values):
    img_k = compress(k, U, s, Vt)
    axes[i+1].imshow(img_k, cmap='gray')
    axes[i+1].set_title(f"k={k}")
    axes[i+1].axis('off')

plt.tight_layout()
plt.show()

    7. Sparse Matrices¶

    Economic networks (e.g., input-output, social graphs) are often sparse: most connections are zero. Storing these as dense arrays wastes memory.

    scipy.sparse stores only non-zero elements.

    N = 5000
# Tridiagonal discretization of a 1D Laplacian (e.g., finite-difference Hessian)
main_diag = -2.0 * np.ones(N)
off_diag = np.ones(N - 1)
A_sparse = sparse.diags(
    diagonals=[off_diag, main_diag, off_diag], offsets=[-1, 0, 1], format="csr"
)

print(f"Sparse Matrix Memory: {A_sparse.data.nbytes / 1e6:.2f} MB")
# Dense equivalent would be N*N*8 bytes ~ 200MB
print(f"Dense Equivalent:     {(N*N*8) / 1e6:.2f} MB")

    Economic Interpretation: Why conditioning is an economic issue¶

    In an estimated equilibrium system, a large condition number means that small sampling, calibration, or rounding errors in moments and coefficients can produce economically large changes in the recovered prices, quantities, or policy coefficients. Decompositions such as QR and SVD are therefore not only numerical conveniences: they diagnose weakly identified directions and distinguish economically meaningful variation from nearly redundant equations.

    Summary¶

    Key Takeaways: * Think Geometrically: Matrices are linear transformations. * Solve, Don't Invert: Use scipy.linalg.solve for speed and stability. * Watch the Condition Number: High \(\kappa(A)\) means unreliable results. * SVD is Powerful: It reveals the underlying structure and rank of data. * Go Sparse: For large networks, sparse matrices are essential.

    Common Pitfalls in This Lecture

    • Explicit inverses. np.linalg.inv(A) @ b is slower and less accurate than np.linalg.solve(A, b), which factors once and never forms the inverse. Also, inv fails outright on singular matrices that lstsq would handle gracefully.
    • Trusting near-solutions. A matrix can be technically invertible yet numerically useless: \(\kappa(A) \approx 10^{12}\) means you lose ~12 digits of precision. Inspect the condition number before interpreting any solution of an ill-conditioned system.

The PageRank vector \(v\) is the principal eigenvector of the Google matrix \(G\), satisfying \(Gv = v\) (eigenvalue \(\lambda=1\)). * Task: Create a random 100x100 transition matrix representing web links. Damping factor \(\alpha=0.85\). Use the Power Iteration method to find the steady-state vector \(v\). Visualize the convergence of the error over iterations.

    Failure analysis (Challenge): Solving an input-output system with inv(A) @ b returns a solution whose residual is large even though \(A\) is technically invertible. Diagnose ill-conditioning by computing \(\kappa(A)\), repair with solve/lstsq plus row scaling, and report the residual before and after alongside the digits lost.
