    Historical Context — Markowitz 1952. Harry Markowitz's 'Portfolio Selection' (Journal of Finance, 1952) recast investing as an optimization over means and covariances rather than rules of thumb — diversification became a theorem. The 1990 Nobel followed; every efficient frontier plotted below descends from that paper.

    The Lens: The Mathematics of Not Putting All Your Eggs in One Basket¶

    Investing is a trade-off. We want high returns, but we hate losing money. For centuries, "diversification" was folk wisdom. In 1952, Harry Markowitz turned it into a science. He showed that the risk of a portfolio is not just the average risk of its stocks, but depends crucially on how they move together (covariance).

    This insight launched Modern Portfolio Theory (MPT). It gave us the "Efficient Frontier" (the best possible portfolios) and eventually led to the CAPM, which told us that the market only pays us for taking risks that cannot be diversified away.

    Economic question. In 01 Portfolio Theory, what must remain economically invariant when the computational representation changes? Financial models connect prices to risk, timing, and no-arbitrage restrictions. The economic question is which states of the world make a payoff valuable, how risk is transferred or hedged, and how sensitive the valuation is to assumptions about dynamics and market completeness. A numerical price is credible only when it respects basic bounds, limiting cases, and an independent replication or hedging argument.

    1. Mean-Variance Optimization¶

    The investor's problem is to choose weights \(w\) to minimize portfolio variance \(\sigma_p^2 = w^T \Sigma w\) subject to a target expected return \(\mu_p = w^T \mu\).

    1.1 Data Loading¶

    We use a dataset of 5 major US stocks and the Fama-French factors. We rely on local data to ensure reproducibility.

        returns_dict[tick] = r_i

    asset_returns = pd.DataFrame(returns_dict, index=dates)
    market_returns = ff_factors['Mkt-RF'] + ff_factors['RF']

    print("> **Note:** Loaded Fama-French factors and generated consistent asset returns.")

except FileNotFoundError:

    2. Testing the CAPM and Fama-French Models¶

    Figure: How the capital market line differs from the security market line..

    The CAPM predicts that a stock's excess return is solely determined by its market beta: $$ E[R_i] - R_f = \alpha_i + \beta_i(E[R_m] - R_f) $$ If the CAPM holds, \(\alpha_i\) should be zero.

    The Fama-French model adds Size (SMB) and Value (HML) factors: $$ E[R_i] - R_f = \alpha_i + \beta_{mkt} MKT + \beta_{smb} SMB + \beta_{hml} HML $$

    Dimension notes: excess returns \(E[R_i] - R_f\) scalars; factor loadings \((\beta_i, s_i, h_i)\) scalar regression coefficients on factor returns SMB, HML, \(E[R_m] - R_f\); \(\alpha_i\) is the scalar pricing error tested against zero.

    # Prepare Regression Data
excess_returns = asset_returns.sub(ff_factors['RF'], axis=0)
X = sm.add_constant(ff_factors[['Mkt-RF', 'SMB', 'HML']])

results = []
for ticker in tickers:
    y = excess_returns[ticker]
    # Drop NaNs created by alignment
    common_idx = y.index.intersection(X.index)
    model = sm.OLS(y.loc[common_idx], X.loc[common_idx]).fit()

    results.append({
        'Ticker': ticker,
        'Alpha (Ann.)': model.params['const'] * 252,
        'Beta Mkt': model.params['Mkt-RF'],
        'Beta SMB': model.params['SMB'],
        'Beta HML': model.params['HML'],
        'R-squared': model.rsquared
    })

res_df = pd.DataFrame(results).set_index('Ticker')
print("> **Note:** Fama-French Factor Loadings:")
display(res_df.style.background_gradient(cmap='coolwarm', axis=0))

    3. The Black-Litterman Model¶

    Mean-Variance Optimization is notoriously sensitive to input errors. A small change in expected return can swing the optimal weight from 0% to 50%. This is "error maximization."

    Black-Litterman solves this by using a Bayesian prior. It assumes the market is efficient (equilibrium) and uses the market cap weights to back out the "implied" expected returns. It then updates these priors with investor views.

    if PYPFOPT_AVAILABLE:
    # 1. Prior: Market Implied Returns
    # We assume arbitrary market caps for demonstration
    mcaps = {'AAPL': 2000e9, 'MSFT': 1800e9, 'AMZN': 1500e9, 'JPM': 400e9, 'XOM': 300e9}
    delta = black_litterman.market_implied_risk_aversion(market_returns)
    prior = black_litterman.market_implied_prior_returns(pd.Series(mcaps), delta, S)

    # 2. Views: Investor believes AAPL will return 20% (Absolute View)
    # and MSFT will outperform JPM by 5% (Relative View)
    views = {'AAPL': 0.20}

    # 3. Posterior
    # Simple implementation with absolute views only for clarity in this demo
    bl = black_litterman.BlackLittermanModel(S, pi=prior, absolute_views=views)
    ret_bl = bl.bl_returns()
    S_bl = bl.bl_cov()

    # 4. Optimize with Posterior
    ef_bl = EfficientFrontier(ret_bl, S_bl)
    w_bl = ef_bl.max_sharpe(risk_free_rate=rf_rate)

    print("> **Note:** Black-Litterman Optimal Weights (View: AAPL=20%):")
    display(pd.Series(ef_bl.clean_weights()).to_frame('Weight').T)

    4. Ledoit-Wolf Shrinkage: Stabilizing High-Dimensional Covariance Matrices¶

    Mean-variance portfolios are extremely sensitive to covariance estimation. When the number of assets is not small relative to the sample size, the sample covariance matrix is noisy and can become nearly singular. Ledoit-Wolf shrinkage replaces it with a convex combination

    \[\hat\Sigma_{LW}=\alpha F+(1-\alpha)S,\]

    where \(S\) is the sample covariance and \(F\) is a structured target. The shrinkage intensity is selected to reduce expected squared estimation error. The relevant portfolio diagnostic is not an in-sample Sharpe ratio; it is out-of-sample stability of weights, realized risk, and turnover.

    The code below compares matrix conditioning. A better condition number does not prove a better portfolio, but it removes a major numerical amplification channel and provides a falsifiable reason to test shrinkage out of sample.

    from sklearn.covariance import LedoitWolf
# Synthetic correlated returns with P not tiny relative to T.
_local_rng = np.random.default_rng(2026)
n_obs, n_assets = 120, 60
factor = _local_rng.normal(size=(n_obs, 3))
loadings = _local_rng.normal(scale=0.35, size=(3, n_assets))
returns_lw = factor @ loadings + _local_rng.normal(scale=0.7, size=(n_obs, n_assets))
sample_cov = np.cov(returns_lw, rowvar=False)
lw_cov = LedoitWolf().fit(returns_lw).covariance_
print(f"sample condition number: {np.linalg.cond(sample_cov):.2e}")
print(f"Ledoit-Wolf condition number: {np.linalg.cond(lw_cov):.2e}")
assert np.linalg.cond(lw_cov) < np.linalg.cond(sample_cov)

    Key Equations¶

    These relations are collected from the derivations above as a review map. Their assumptions and derivations remain part of the result; this box is not a substitute for them.

    1. Core relation

    \[E[R_i] - R_f = \alpha_i + \beta_i(E[R_m] - R_f)\]

    2. Core relation

    \[E[R_i] - R_f = \alpha_i + \beta_{mkt} MKT + \beta_{smb} SMB + \beta_{hml} HML\]

    3. Core relation

    \[\hat\Sigma_{LW}=\alpha F+(1-\alpha)S,\]

    Dimension notes: returns, betas and alphas are scalars; factor premia enter as scalar regressors; test statistics compare scalar estimates to their standard errors.

    Common Pitfalls in This Lecture

    • Error-maximizing weights. Mean-variance optimizers eat estimation error: sampling noise in means produces extreme 'optimal' portfolios that fail out of sample. Constrain weights, shorten the horizon to reduce mean noise, or shrink covariances (Ledoit-Wolf).
    • Annualization slips. Scaling monthly Sharpe ratios requires multiplying the mean by 12 but the volatility by \(\sqrt{12}\); mixing these inflates ratios ~40%. Align frequency of returns, risk-free rate and scaling exponents.

    4. Summary¶

    1. MVO: The Efficient Frontier defines the theoretical limit of diversification. However, it is sensitive to garbage-in, garbage-out data.
    2. Factor Models: Returns are driven by systematic risks. The Fama-French model shows that Size and Value are compensated risk factors alongside the Market.
    3. Black-Litterman: By anchoring to the market equilibrium, we get robust portfolios that only deviate from the market index when we have strong, specific views.
    # --- Efficient Frontier Construction ---
import scipy.optimize as sco

# Synthetic Asset Returns (3 Assets)
n_obs = 1000
returns = np.random.multivariate_normal(
    mean=[0.10, 0.12, 0.15],
    cov=[[0.01, 0.002, 0.005], [0.002, 0.02, 0.01], [0.005, 0.01, 0.03]],
    size=n_obs
)
mean_returns = returns.mean(axis=0)
cov_matrix = np.cov(returns.T)
num_assets = 3

def portfolio_volatility(weights):
    return np.sqrt(np.dot(weights.T, np.dot(cov_matrix, weights))) # Matrix multiplication

def portfolio_return(weights):
    return np.sum(mean_returns * weights)

# Monte Carlo Simulation
p_ret = []
p_vol = []
for _ in range(5000):
    weights = rng.random(num_assets)
    weights /= np.sum(weights)
    p_ret.append(portfolio_return(weights))
    p_vol.append(portfolio_volatility(weights))

p_ret = np.array(p_ret)
p_vol = np.array(p_vol)

# Efficient Frontier Optimization
target_rets = np.linspace(p_ret.min(), p_ret.max(), 50)
efficient_vol = []
for tret in target_rets:
    constraints = ({'type': 'eq', 'fun': lambda x: portfolio_return(x) - tret},
                   {'type': 'eq', 'fun': lambda x: np.sum(x) - 1})
    bounds = tuple((0, 1) for _ in range(num_assets))
    result = sco.minimize(portfolio_volatility, num_assets*[1./num_assets,], method='SLSQP', bounds=bounds, constraints=constraints) # Minimize objective function
    efficient_vol.append(result['fun'])

plt.figure(figsize=(10, 6))
plt.scatter(p_vol, p_ret, c=p_ret/p_vol, marker='o', cmap='viridis', alpha=0.3, label='Random Portfolios')
plt.plot(efficient_vol, target_rets, 'r--', linewidth=3, label='Efficient Frontier') # Plot data series
plt.colorbar(label='Sharpe Ratio')
plt.xlabel('Volatility (Std. Dev)')
plt.ylabel('Expected Return')
plt.title('Efficient Frontier')
plt.legend()
plt.show() # Render plot
