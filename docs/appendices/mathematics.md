# Mathematics Review

The mathematical appendix is designed as a proof-bearing reference for the computational modules rather than a detached formula sheet.

- [A1 — Real Analysis](../notebooks/Appendix/A1-Real-Analysis.md): metric spaces, compactness, contraction arguments, continuity.
- [A2 — Multivariate Calculus](../notebooks/Appendix/A2-Multivariate-Calculus.md): Jacobians, Hessians, implicit functions, KKT conditions, envelope theorem, comparative-statics proofs.
- [A3 — Probability Theory](../notebooks/Appendix/A3-Probability-Theory.md): conditional expectation, LLN/CLT, common distributions, martingales, sampling-limit proofs.
- [A4 — Linear Algebra](../notebooks/Appendix/A4-Linear-Algebra.md): eigensystems, decompositions, spectral theorem, positive definiteness, conditioning.
